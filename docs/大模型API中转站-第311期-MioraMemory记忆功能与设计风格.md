# Miora Memory 如何把审美偏好写成可执行规则
长期记忆的价值不在于让工具记住一张图片，而在于把稳定的审美偏好写成下一次可以执行的规则。本文围绕 Miora Memory，区分临时素材、长期偏好和可复用流程，说明如何从满意作品中提炼颜色、排版、语气和禁用项，并通过新任务验证是否真的生效。文中只讨论可复现的步骤，不把单次结果扩展成产品承诺；每个结论都标注前提、证据和无法覆盖的边界。读者可以先完成最小验证，再按自己的版本、权限和数据补充实验。


上一期我们用 Miora 跑通了一张海报。

但如果下一次换成书店活动、咖啡促销或个人 IP 封面，你还要重新解释一遍“留白多一点、颜色克制一点、标题要大、不要霓虹”吗？

如果每次都要重新说，Miora 就只被你当成了一个带画布的生图工具。

它真正值得学的部分，是 Memory。

普通工具通常把每次对话当成一次性任务。Miora 的 Agent Memory 则试图把你稳定的创作规则保存下来：品牌色、字体气质、版式习惯、语言调性、禁用项，以及某个项目后续要持续遵守的上下文。

这不是让 AI“拥有真正的人格”，也不是保证每一次生成都完全一致。Memory 更像一份会被 Agent 读取的审美说明书。说明书越具体，越容易被执行；越空泛，越容易变成无效形容词。

项目入口：[Miora](https://miora.design/)

## 一、Memory 记住的不是图片，而是规则

先区分三种东西：

| 内容 | 例子 | 更适合放在哪里 |
| --- | --- | --- |
| 临时素材 | 本次海报的一张参考图 | 当前画布或当前任务 |
| 稳定偏好 | 主色、留白、排版和禁用项 | 长期 Memory |
| 重复流程 | Logo 全案、电商主图、分镜制作步骤 | Skill |

如果你喜欢某一张图，不代表你应该把这张图本身写进长期记忆。更有价值的是提炼它背后的规则：

~~~text
这张图用了什么主色？
标题和主体的层级是什么？
留白比例大概怎样？
字体给人的感觉是什么？
哪些元素被明确排除了？
这些规则是否会在下一个项目继续使用？
~~~

一句话记忆：

~~~text
Memory 决定“结果像不像你”
Skill 决定“流程能不能一整套跑完”
当前素材决定“这一次具体要做什么”
~~~

这三个层次混在一起，就会出现两种问题：把一次性的赛博朋克实验写成永久品牌规范，或者把完整的品牌工作流误以为只要记住几个颜色就能自动复现。

## 二、为什么“高级感”不是一条好记忆

很多人给 AI 的长期偏好是这样的：

~~~text
请记住我喜欢高级感、简约、时尚和有质感。
~~~

这句话听起来没错，但执行信息太少。

“高级感”可以是黑金、米白、银灰、极简摄影、电影光影，也可以是大量留白、细衬线字体或低饱和插画。不同人心里对这个词的理解不同，AI 也只能根据上下文猜。

更可执行的写法应该把抽象感觉拆成能被检查的维度：

~~~text
整体风格：极简、克制、文艺，避免强烈商业促销感。
主色：米白和浅咖，深棕只用于标题或重点信息。
排版：大标题、居中或左对齐，保持较大留白。
图形：少量自然元素，避免装饰堆叠。
文字：短句、清晰、温和，不使用夸张感叹号。
禁止：霓虹、二次元、廉价贴纸、过度渐变、复杂背景。
~~~

两者的区别是：前者是形容词，后者是规则。

规则可以被检查，也可以在出错时修改。以后生成一张“秋日书店开业”海报时，你可以明确判断：

- 颜色是否仍然是米白和浅咖？
- 标题是否保持大而清晰？
- 背景是否出现了禁用的霓虹或贴纸？
- 文案是否依然克制？

这才是 Memory 的工程化用法。

## 三、四步跑通一次长期记忆

第一次不要一登录就把十几条规则全部写进去。最稳的方式是先做出满意结果，再提炼、检查、回归。

### 第一步：先完成一件你真的满意的作品

你必须先确认自己想长期保留什么。

如果第一张图本身还在不断变化，直接让 Miora 记忆，很可能把临时试验、偶然效果和真正的品牌规则混到一起。

建议先选择一个小任务：

- 一张社交媒体封面。
- 一张活动海报。
- 一个简单 Logo 方向。
- 一张个人 IP 的栏目头图。

完成后，不要只问“好不好看”，而要给结果做一次拆解：

~~~text
我喜欢这张图的哪些地方？
哪些地方即使换主题也想保留？
哪些地方只是这次活动才需要？
哪些地方其实应该修正，而不是记住？
~~~

### 第二步：把稳定规则写进 Memory

直接发一段结构化指令：

~~~text
请把下面内容写入长期记忆，后续同类设计任务默认沿用：

1. 整体风格：极简、干净、克制，保留较多留白。
2. 主色：米白和浅咖，深棕只用于标题或重点信息。
3. 排版：标题要大、清晰、层级明确，优先居中或左对齐。
4. 图片气质：自然光、低饱和、轻微电影静帧感。
5. 文案：短句、温和、少用夸张感叹号。
6. 禁止：霓虹、二次元、廉价贴纸、复杂渐变和过度装饰。
7. 适用范围：品牌海报、社交媒体封面和活动宣传图。
~~~

这段指令同时说明了规则内容和适用范围。适用范围很重要，因为你可能平时喜欢电影感，但做一个游戏角色时并不想永远使用同一套视觉。

### 第三步：去 Memory 入口检查

不要发送完指令就默认它记对了。打开左侧的 Memory 入口，看它实际保存了什么。

重点检查四件事：

1. 有没有漏掉关键规则？例如你写了主色和禁用项，但没有保存留白要求。
2. 有没有把临时内容记成长期规范？例如只在这次开业海报使用的日期和促销文案。
3. 有没有把模糊词改写成与你本意不同的规则？例如把“少量自然元素”变成“所有画面都必须有植物”。
4. 有没有两条规则互相冲突？例如既要“充足留白”，又要求“画面信息尽可能丰富”。

发现错误就当场编辑，不要等到生成十张错误作品后再排查。Memory 之所以有价值，正是因为它应该可查看、可修正，而不是一个只能相信的黑箱。

### 第四步：只换主题，测试记忆有没有生效

新建一个任务，但不要重复写风格规则：

~~~text
请调用我之前保存的品牌视觉记忆，做一张“书店周末阅读日”海报。
只更换主题、文案和必要的场景元素，保持已记住的配色、排版、留白和整体气质。
请不要重新发明一套风格。
~~~

然后逐条对照：

~~~text
主题换了没有？
品牌色是否仍然一致？
标题层级是否一致？
禁用项有没有再次出现？
结果是否仍然适合实际发布？
~~~

如果结果明显偏离，不要马上得出“Memory 没用”的结论。先检查记忆内容是否清晰、当前任务是否属于适用范围、画布里是否有新的参考图覆盖了原规则，以及你是否要求了彼此冲突的特殊效果。

## 四、个人记忆和项目记忆怎么分

素材里提到，Miora 的记忆可以区分个人记忆和项目记忆。实际界面和命名可能随版本调整，但这个分层思路很值得保留。

### 1. 个人记忆，放长期审美偏好

个人记忆适合保存跨项目都成立的内容：

~~~text
我偏好的设计节奏
我常用的文字语气
我长期不喜欢的视觉元素
我处理标题、留白和层级的习惯
我在社交媒体内容中偏好的信息密度
~~~

例如：

~~~text
请记住我的通用创作偏好：
我喜欢克制、清晰、有留白的画面。
文字要少而重要，不要用大量装饰填空。
默认避免霓虹、过度美颜、复杂贴纸和密集小字。
如果需求没有指定风格，优先给我两种简洁、现代的方向供选择。
~~~

### 2. 项目记忆，放某个品牌的特殊规范

项目记忆适合保存只对某个项目成立的内容：

- 某品牌的标准色和 Logo 位置。
- 某个栏目固定的封面比例。
- 某款产品的角色设定和世界观。
- 某个客户要求禁止出现的人物、场景或用词。
- 某次活动的具体视觉主题。

例如一个咖啡品牌可以有：

~~~text
项目记忆：青芽咖啡
主色：奶油白、深棕、少量橄榄绿。
Logo：优先放在右下角，保持安全边距。
产品摄影：自然光、木质桌面、少量真实食材。
文案：温和、简洁，不使用“全网最低”等夸张词。
禁止：霓虹灯、卡通咖啡杯、过度饱和的橙色。
~~~

这样，个人记忆决定你普遍偏好的创作方式，项目记忆决定当前品牌的具体约束。两者同时生效时，要注意优先级和冲突处理。

### 3. 不要把所有规则都放到个人记忆

如果你把每个客户的主色、每个活动的日期、每个产品的 Logo 位置都写进个人记忆，后面一定会互相打架。

可以用一个简单判断：

~~~text
换项目后仍然成立 -> 个人记忆
只对这个品牌成立 -> 项目记忆
只对本次任务成立 -> 当前 Prompt 或画布
可以反复执行的步骤 -> Skill
~~~

这个判断比“系统到底把它保存到了哪个菜单”更重要。菜单会改，信息边界不会。

## 五、从自己的成品图逆向提炼风格

很多人知道自己喜欢什么，但说不清楚为什么喜欢。此时不要硬编一堆形容词，可以让 Miora 先分析你自己的成品。

### 1. 选择一组有代表性的作品

不要只挑一张偶然做得好的图。最好选择三到五张你确实愿意长期使用的作品，并尽量满足：

- 不是同一个活动的完全重复版本。
- 有不同主题，但整体气质接近。
- 文字、构图、图片和色彩都有可比较的部分。
- 确认这些作品可以作为风格参考。

### 2. 先让它分析，不要直接让它记忆

把成品放到画布上，先发：

~~~text
请分析画布中这组作品的共同设计规律，分别说明：
1. 主色、辅助色和颜色使用比例；
2. 标题、正文、Logo 和装饰元素的层级；
3. 构图、主体位置和留白节奏；
4. 字体气质和文案长度；
5. 图片的光线、材质和情绪；
6. 不建议出现的元素。

请把结果写成一份具体的设计规范，区分“稳定规则”和“这几张图的临时内容”。
先不要写入长期记忆，等我确认后再执行。
~~~

这里特意加了“先不要写入长期记忆”。让模型先分析、再让你确认，可以减少误记。

### 3. 人工筛选之后再写入

如果分析结果把某个偶然元素总结成了永久规则，删掉它；如果漏掉了你真正看重的东西，补充它。确认后再发：

~~~text
我确认下面这些是长期有效的规则，请写入当前项目记忆：
[粘贴确认后的规则]
请不要保存作品中的日期、临时文案、一次性活动名称和具体人物。
~~~

这一步的本质不是“让 AI 复制我的图”，而是把你自己的视觉方法提炼成可复用的规范。素材来自你自己的作品时，风格分析更有意义；如果使用别人的成品，要先确认版权和使用边界。

## 六、五条可以直接复制的 Memory 指令

### 1. 直接写入一套品牌规则

~~~text
请把以下内容写入当前项目的长期记忆，后续同类创作默认遵守：
- 视觉：极简、干净、克制，留白充足。
- 主色：米白和深棕，辅助色只使用低饱和绿色。
- 排版：标题大而清晰，正文少而易读，Logo 保持安全边距。
- 图片：自然光、真实材质、轻微电影感。
- 禁止：霓虹、二次元、复杂贴纸、过度装饰和密集小字。
- 适用：品牌海报、社交媒体封面、活动宣传图。
请写入后列出保存结果供我检查。
~~~

### 2. 从当前满意结果沉淀规则

~~~text
请根据当前画布中我确认满意的结果，总结一套可复用的设计规范。
包括配色、构图、字体气质、留白、信息层级、图片光线和禁用项。
先列出分析结果，不要自动写入长期记忆。
~~~

### 3. 调用已有记忆做新内容

~~~text
请调用我已有的品牌视觉记忆，做一张“秋日书店开业”海报。
只更换主题、场景和文案，保持配色、排版、留白和整体气质一致。
如果新需求和已有规则冲突，请先指出冲突，不要直接覆盖记忆。
~~~

### 4. 修正错误记忆

~~~text
请修改当前项目记忆：
删除“可以使用霓虹渐变”这一条；
改为“默认使用低饱和配色，不使用霓虹渐变，除非我在当前任务中明确指定”。
修改后请列出相关规则的当前版本。
~~~

### 5. 做一次记忆盘点

~~~text
请列出你目前保存的关于我的个人记忆和当前项目记忆。
每条标记：长期规则、项目规则还是临时上下文。
指出可能冲突的内容，并告诉我哪些规则会在下一次设计中默认生效。
不要自行新增或删除任何记忆。
~~~

第五条很重要。记忆系统使用一段时间后，必须定期盘点，否则规则会越积越多，最终互相覆盖。

## 七、三个最容易踩的坑

### 坑一：只用，不沉淀

你已经连续做了十张同风格封面，却每次重新写“米白、留白、简约、不要花哨”。这相当于主动关闭了 Miora 的长期能力。

正确做法是：完成三到五次稳定创作后，提炼一份规则，再用下一张图做回归测试。

### 坑二：记得太虚

“高级一点”“有质感”“更国际化”无法直接验收。把它们改成配色、版式、字体气质、图片光线、信息密度和禁用项。

你可以保留抽象词，但必须给出解释：

~~~text
高级感 = 低饱和配色 + 大留白 + 少装饰 + 清晰层级
温柔 = 柔和自然光 + 低对比 + 短句文案 + 不使用强烈警示色
现代 = 几何结构 + 简洁字体 + 明确栅格 + 不使用复古贴纸
~~~

### 坑三：把临时实验写进长期规则

今天做赛博朋克活动图，明天做手绘儿童节海报，后天做极简企业封面。如果你每次试验都要求“记住”，长期记忆必然会打架。

一个简单原则：

~~~text
只记你确认未来还会使用的规则。
临时实验放在当前画布，满意后再决定是否沉淀。
~~~

## 八、Memory 和 上游 API 的企业价值如何连接

个人创作时，Memory 主要解决“每次都从头解释风格”。企业创作时，它还会影响团队协作和模型治理。

一个团队可以把品牌规则拆成三层：

~~~text
Miora Memory：创意人员和项目使用的品牌偏好
企业知识库：已审批的 Logo、色板、文案和品牌规范
上游 API 企业API网关：生产工作流调用模型时的统一入口
~~~

当运营在 Miora 里确认一套视觉方向后，团队可以把经过审核的规则和资产版本化，再同步到自己的内容生产、Agent、客服或 SaaS 系统。上游 API 则负责后续多模型统一接入、模型路由、Key 权限、调用追踪和成本治理。

不要把 Miora 的个人记忆直接当成企业的合规知识库，也不要让未经审核的临时风格规则自动进入所有项目。企业需要额外做：

- 个人偏好和品牌规范分离。
- 设计规则变更需要版本和审批。
- 通过 上游 API 的 Key 按项目、环境和角色隔离。
- 记录哪个模型、哪个项目、哪个版本的规则生成了资产。
- 对客户素材、未发布产品和内部品牌文件做权限控制。

上游 API 的营销重点在于把创意探索之后的生产调用管起来：同一品牌在图片、文案、视频脚本和知识库问答中使用不同模型，也能保持统一 API 入口、预算、日志和权限。

## 九、Memory 的质量怎么评估

不要用“我感觉这次更像了”作为唯一指标，可以建立一个很小的回归集。

### 1. 准备固定问题

准备五个不同主题，但都要求使用同一套品牌规则：

~~~text
咖啡促销海报
书店阅读日封面
轻食新品发布图
个人 IP 栏目头图
线下活动立牌
~~~

### 2. 记录五项结果

| 维度 | 检查问题 |
| --- | --- |
| 配色一致 | 主色和辅助色是否越界 |
| 排版一致 | 标题、Logo 和留白是否稳定 |
| 禁用项 | 是否出现明确禁止的元素 |
| 任务适配 | 换主题后是否仍然适合使用场景 |
| 可修改性 | 出错后能否只改局部而不破坏全图 |

### 3. 遇到漂移先查原因

结果不一致可能有多种原因：

- Memory 规则太抽象。
- 当前任务的特殊需求覆盖了长期规则。
- 画布里放了冲突的参考图。
- 当前生成模型的随机性或能力不同。
- Agent 没有把相关规则带入当前任务。
- 你的品牌规范本来就没有定义清楚。

先定位原因，再决定是修 Memory、换模型、改 Prompt 还是接受当前差异。不要把所有问题都归因给 Memory。

## 十、安全和成本边界

- 记忆里不要写 API Key、数据库密码、客户身份证号、合同全文等敏感信息。
- 上传个人作品或客户资产前，确认你拥有使用权，尤其是训练、分析和团队分享范围。
- 记忆内容可能影响后续输出，涉及客户项目时要区分个人、项目和团队可见范围。
- Miora 的活动积分、模型价格、输出格式和功能上限会变化，以当前页面实际显示为准。
- 记忆保持一致不等于生成结果拥有商用授权，也不等于 Logo、字体和人物素材没有版权风险。
- 上游 API 可以治理企业模型调用的 Key、预算、路由和日志，但不能替你完成品牌资产授权、数据分类和人工审核。

## 十一、Memory 验收清单

### 记忆内容

- [ ] 已把抽象形容词拆成配色、排版、留白、语气和禁用项。
- [ ] 已区分个人长期偏好、项目规则和本次临时要求。
- [ ] 没有把日期、临时文案或一次性活动写进长期记忆。
- [ ] 记忆规则没有互相冲突，适用范围写清楚了。

### 记忆操作

- [ ] 先完成满意作品，再提炼记忆。
- [ ] 写入后打开 Memory 看板检查实际保存内容。
- [ ] 能修改错误规则并确认修改结果。
- [ ] 新任务只换主题，能够验证记忆是否真的生效。
- [ ] 至少用三到五个不同主题做过小型回归测试。

### 企业治理

- [ ] 未把敏感凭证和客户原文写入 Memory。
- [ ] 品牌规范、个人偏好和临时创意有清晰的权限边界。
- [ ] 需要接入自有应用时，已评估通过 上游 API 做企业 API 统一入口。
- [ ] 上游 API 的 Key、预算、模型路由和调用日志按项目或环境拆分。

## 总结

Miora Memory 最值得学习的，不是“AI 终于会记住我”这句宣传，而是它提醒我们：创作偏好必须从感觉变成规则。

~~~text
先做出满意结果
  -> 拆解配色、排版、留白和禁用项
  -> 写入 Memory
  -> 打开看板检查和修正
  -> 只换主题做回归测试
  -> 把稳定规则复用到下一次项目
~~~

普通工具每次都把你当陌生人；稳定、可检查的 Memory，才会让工具逐渐接近你的创作方式。下一篇继续讲另一条主线：无限画布和 Skills 如何把一张图扩展成一整套可复用的品牌工作流。
