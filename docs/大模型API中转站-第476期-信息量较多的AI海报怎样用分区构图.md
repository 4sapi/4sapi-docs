# 信息量较多的 AI 海报怎样用分区构图

海报一旦同时出现两个对象、两种观点或一组需要比较的信息，自由摆放通常很快失控：左边一张图、右边一张图、标题压在中间，日期又被挤到角落。看似元素都放进去了，观众却不知道两边有什么关系，也不知道先读哪边。

解决办法不是继续缩小文字，而是先把画面切成有职责的区域。本文介绍 L 型锚定和左右分屏两种分区构图，分别适合“主视觉 + 边缘信息轨道”与“双对象 / 前后对比 / 联名主题”。两种方法都可以写成图像生成提示词，也可以用 CSS Grid 稳定实现。

## 分区前先回答四个问题

分区不是把画布平均切开。开始前先明确：

```text
两个区域之间的关系是什么：对比、顺序、主从，还是共同发布？
哪个区域先被看到，为什么？
标题是属于一侧，还是需要跨越边界？
日期、说明、行动信息应该固定在哪个稳定区域？
```

如果两侧没有可说的关系，就不该为了“丰富画面”强行做分屏。若一侧只是装饰，使用非对称平衡或大留白往往更清楚。分区适合内容本身需要被并置或被边界组织的情形。

| 构图 | 区域关系 | 适合的内容 | 主要风险 |
| --- | --- | --- | --- |
| L 型锚定 | 一条竖轨与一条横轨在角落相交，托住开放主视觉区 | 建筑、展览、目录、工业主题 | 四边都加栏，变成压迫的框 |
| 左右分屏 | 两个并列区域呈现对比或合作，允许 60/40 主次 | 前后变化、双人、产品比较、联名 | 两边完全同权，画面没有入口 |

## 1. L 型锚定：给信息一条边缘轨道

L 型由一条竖向信息带和一条横向信息带在角落相交组成。它像支架：边栏承载编号、分类或纵向文字，底栏承载标题、日期和说明，剩下的大区域留给主视觉。与框中框不同，L 型故意只占两条边，让画面保留一个开放方向。

### 先分配两条轨道的职责

```text
竖轨：编号、系列名称、地点、分类或短标签。
横轨：主标题、日期、简短说明和行动信息。
开放区：唯一主视觉，允许有足够尺度和留白。
角点：两条轨道的交接，不放第三个竞争焦点。
```

```text
制作一张 3:4 竖版建筑展海报，采用 L 型锚定。
左侧保留约 18% 宽度的竖向信息轨，放“ARCHIVE 06”和展览编号；
底部保留约 20% 高度的横向标题带，放主标题“材料如何记忆城市”、日期和地点。
右上开放区域展示一张混凝土建筑局部，作为唯一主视觉。
视线先沿左边信息轨下行，在左下角转向底部标题，再进入右上照片。
不要封闭右边和顶部；不要让竖轨、底栏和照片同时使用高饱和背景。
```

CSS Grid 可以天然表达两条轨道。正文若需要竖排，应先确认目标语言、字体和投放环境是否适合；`writing-mode` 只用于确有必要的短信息，不应用在大段说明上。MDN 的 [writing-mode 文档](https://developer.mozilla.org/en-US/docs/Web/CSS/writing-mode)说明了不同书写方向的基本行为。

```css
.poster {
  display: grid;
  grid-template-columns: 18% 1fr;
  grid-template-rows: 1fr 20%;
  min-block-size: 720px;
}
.poster__rail { grid-column: 1; grid-row: 1; padding: 1rem; }
.poster__visual { grid-column: 2; grid-row: 1; overflow: hidden; }
.poster__bar { grid-column: 1 / -1; grid-row: 2; padding: 1rem 1.25rem; }
.poster__rail-label { writing-mode: vertical-rl; }
```

### 验收 L 型有没有真的“托住”主视觉

在首稿中临时给竖轨和底栏加不同底色。检查三件事：

1. 去掉照片后，两条轨道能否独立说明海报主题和时间？
2. 去掉轨道后，照片是否仍然是清楚的主视觉，而不是一张被边栏压得很小的缩略图？
3. 角点是否自然地把视线从竖向交接到横向，而不是积聚了过多 logo、图标和小字？

移动端若继续使用竖轨和底栏，容易让开放区变得太窄。可以保留底栏，将竖轨改为顶部短标签，或把其内容移动到标题上方的普通横排，而不是固守桌面比例。

## 2. 左右分屏：把“并置”变成明确的比较

左右分屏用于两个对象、两个时间点、两个方案或两个合作方之间存在明确关系的内容。最关键的选择不是有没有中缝，而是两侧谁承担主角。若用户需要先看一个对象再理解另一个，60/40 或 70/30 的比例通常比机械的 50/50 更容易建立入口。

### 明确比较维度和标题归属

先写清两边各自代表什么，以及观众要比较什么。颜色、材质、人物朝向和文字语气可以加强关系，但不能代替关系本身。

```text
制作一张横版产品更新海报，采用左右分屏的 60/40 比例。
左侧 60% 展示“旧流程”：多个手工步骤和较低对比的灰色界面；
右侧 40% 展示“新流程”：一个清晰的自动化流程卡片，使用更明亮但不过饱和的强调色。
主标题“从排队处理到一次完成”跨越中缝，副标题放在左侧，发布日期放在右下。
先让观众看到左侧的问题，再跨越中缝理解右侧的变化。
不要把两侧做成毫无差别的镜像；不要用未经证实的效率数字强化对比。
```

网页版本可用五列 Grid 建立 3/2 的区域比例。跨缝标题应当有可靠背景，不能恰好压在两个复杂图像的分界线上：

```css
.poster {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
  min-block-size: 560px;
}
.poster__left { grid-column: 1 / 4; padding: clamp(20px, 4vw, 64px); }
.poster__right { grid-column: 4 / 6; padding: clamp(20px, 4vw, 64px); }
.poster__title {
  grid-column: 2 / 5;
  grid-row: 1;
  align-self: center;
  z-index: 1;
}
```

如果两侧有可交互内容，不要只靠颜色传达状态或归属。文字标题、图标或清晰的标签需要同时存在；这也能帮助灰度打印、低质量屏幕和不同色觉条件下的阅读。

### 三种左右分屏的任务写法

#### 前后变化

```text
左侧是“准备前”，右侧是“完成后”；两边使用同一对象、同一视角和相近裁切，
只突出与主题有关的变化。中缝是时间交接，不要添加无关的第三种状态。
```

适用于改造、修复、流程前后。若素材视角不同，观众无法判断变化来自产品还是来自拍摄方式，应改用标注或单一时间线。

#### 两种方案比较

```text
左侧展示方案 A 的适用条件与限制，右侧展示方案 B 的适用条件与限制。
标题明确比较维度；两侧信息字段顺序一致，不把一侧写成广告语、另一侧写成长段正文。
```

适用于选型和对比说明。信息字段一致比视觉对称更重要；没有统一维度时，分屏会制造一种虚假的可比性。

#### 联名或双主角

```text
两位主角分别占据左右区域，视线或姿态朝向中缝；
联名标题跨越中缝，日期与共同信息统一放在底部。
一方尺度略大，另一方用色彩或文字组回应，避免双主角互相遮挡。
```

联名场景并不意味着双方必须完全一样大。若品牌约定需要等权展示，则可以使用 50/50，但仍要规定标题、标志和行动信息的共同位置。

## 从分区图到可交付 HTML 的任务书

将下面模板中的内容替换为真实素材信息。它的目标是让 Agent 先确认区域关系，再实现视觉细节。

```text
目标：制作一张【比例】的【L 型锚定 / 左右分屏】海报，用于【场景】。
内容关系：区域 A 与区域 B 是【主从 / 前后 / 对比 / 联名】关系。
阅读入口：先看【区域或对象】；最终停在【日期、CTA 或结论】。

区域定义：
- 区域 A：占【比例】，内容为【对象和文字】，层级为【一级/二级】。
- 区域 B：占【比例】，内容为【对象和文字】，层级为【一级/二级】。
- 跨区内容：标题【是否跨越边界】；元信息固定在【位置】。

实现要求：用 CSS Grid 建立区域，不以全页绝对定位模拟；
文字与外边缘保持【安全距离】；图片裁切不伤及【关键部分】；
窄屏改为【单列/顶部标签+底栏/上下顺序】，禁止横向滚动。

验收：桌面与 390px 宽度下，区域关系可识别；标题不与中缝或图片细节冲突；
所有文本完整可读，主行动不被固定元素遮挡。
```

## 分区构图的常见失败

### 两边内容没有关系

两个漂亮图像并排不等于对比。若无法用一句话说明“为什么这两边必须同时出现”，删去一边或改用普通主视觉。分区的意义来自比较、顺序或合作关系。

### 50/50 造成双焦点

平均分屏很容易让人来回看，却不知道入口。先让一侧在面积、明度、信息密度或标题位置上成为主导；如果业务必须等权，则让跨缝标题成为唯一的共同一级焦点。

### 分割线成为最抢眼的元素

粗中缝、强阴影或霓虹色会把“关系”变成“隔离”。除非主题就是冲突或对抗，否则优先让色彩、朝向、排版和内容字段建立关系，中缝只保持可识别。

### 移动端把两栏硬缩小

桌面上的左右关系并不一定适合手机。小屏常见的安全做法是按原来的阅读优先级变成上下顺序，并用标题、标签或短分割线保留关系。关键是信息顺序不变，而不是画面比例不变。

## 结论与限制

当海报必须同时容纳多个对象或信息组时，先分区能避免无序堆放。L 型锚定让边缘信息托住开放主视觉；左右分屏让两方内容在同一画面中形成可理解的比较、变化或合作关系。

但分区不是信息过载的万能修复。长段说明、复杂表格和大量可选操作更适合网页、详情页或多张系列图。海报仍需要一个清楚入口；先写明区域关系和主次，再让 AI 生成画面，才能保留可读性。
