# 【大模型API中转站】第94期 图片模型4K验货 | 反掺水检查清单

本文是【大模型API中转站】系列的第94篇。本系列致力于用最低的成本、最清晰的方法，帮你打通多模型API的任督二脉。建议先收藏，随用随查。

最近图片模型越来越卷。

很多中转站会写：

```text
支持 4K。
支持高清。
支持超清出图。
支持最新图片模型。
```

但你真正下载图片后，看到的只是：

```text
3840 x 2160
4096 x 4096
PNG
JPG
```

这个数字本身没有意义。

因为一张 720P 或 1080P 的图，完全可以通过超分辨率、插值算法、锐化滤镜，硬拉到 4K。

文件属性会显示 4K。

但细节不一定是 4K。

这篇就讲一个很实用的问题：

```text
怎么判断图片模型是不是“掺水”？
```

这里的掺水，不是说所有超分都不好。

超分本身是正常技术。

问题在于：

```text
明明按高价 4K / 高端模型收费。
实际却给你低分辨率结果再拉伸。
```

如果你只是拿来发朋友圈，可能无所谓。

但如果你要做：

```text
商品主图
品牌海报
广告素材
UI 视觉稿
印刷物料
电商详情页
短视频封面
```

那就不能只看“分辨率”三个字。

你需要一套验货方法。

更好的做法，是把图片模型接入放到 4SAPI 这类可追踪的大模型 API 中转站里。

原因很简单：

```text
模型名要清楚。
调用记录要能查。
图片尺寸要能复核。
小样和终稿成本要分开。
每次生成都要能回溯。
```

4SAPI 的价值不只是让你能调图片模型，而是让你在验货时知道：这张图到底是哪个模型、哪个 Key、哪次请求、哪个成本档生成的。

## 1. 先说结论：不要相信文件属性

判断一张图是不是原生 4K，不能只看：

```text
宽度：3840
高度：2160
文件大小：8 MB
格式：PNG
```

这些都可以被后处理改变。

真正要看的是：

```text
微观细节有没有自然存在。
高频纹理是不是连续。
文字和符号有没有被 AI 脑补。
边缘是不是被强行锐化。
噪点是不是被抹成塑料。
频谱图有没有异常断层。
```

最常见的“虚标 4K”有三类：

```text
1K 或 1080P 直接插值放大到 4K。
1K 图经过 AI 超分后冒充原生 4K。
低价图片模型结果经过锐化、降噪、压缩后包装成高清模型。
```

传统插值的问题是糊。

AI 超分的问题是会“编”。

锐化滤镜的问题是边缘假。

降噪滤镜的问题是画面太干净，像抹了一层胶。

所以验货不是看一项指标，而是看一组证据。

## 2. 中转站图片模型常见掺水方式

先把坑讲清楚。

第一种：尺寸掺水。

实际生成 1024 x 1024。

返回前放大到 4096 x 4096。

你下载后看到是 4K，但真实细节密度还是低分辨率。

第二种：模型掺水。

页面写的是高端图片模型。

后台实际调用低价模型，再用增强算法补一层锐度。

这种最难查，因为普通用户只能看到输出图。

第三种：质量档掺水。

同一个图片模型可能有不同质量档、尺寸档、速度档。

低档生成再拉伸，冒充高档输出。

第四种：压缩掺水。

生成时可能还行。

但中转站、CDN、图床又压缩一遍。

最后交付给你的图已经丢了高频细节。

第五种：预览图冒充成品图。

有些工作流会先出低清小样，再异步生成高清成品。

如果只把小样放大返回，也会让人误以为模型能力差。

这也是为什么我建议用 4SAPI 做图片模型验收底座。

至少你可以在 4SAPI 后台把图片模型调用和 Key 拆开：

```text
4SAPI-Image-Preview：低成本小样。
4SAPI-Image-Final：高质量终稿。
4SAPI-Image-Test：模型验收专用。
4SAPI-Image-Team：团队生产专用。
```

一旦成本、模型名、调用日志都能对上，验货就不是吵架，而是看证据。

## 3. 第一层：放大到 200% 和 400% 肉眼看

最直观的方法，就是把图片放大到 200% 或 400%。

不要看整张图。

要看小区域。

尤其看这些位置：

```text
头发边缘
衣服纤维
墙面纹理
皮肤毛孔
远处文字
路牌标识
商品 logo
金属反光
树叶边缘
建筑窗格
```

### 3.1 看噪点和颗粒

原生高分辨率图，细节不会全部像玻璃一样干净。

它通常会有自然的颗粒：

```text
传感器暗噪点。
胶片颗粒。
材质本身的微小纹理。
阴影里的细碎变化。
```

这些颗粒是像素级、自然、连续的。

如果一张所谓 4K 图放大后看起来异常干净，皮肤像塑料，布料像涂平，阴影像被磨皮，就要警惕。

这通常说明它经过了：

```text
降噪
平滑
AI 超分
油画化增强
```

当然，AI 原生生成图本来就可能比较干净。

所以不能只凭“干净”判死刑。

但如果它同时出现文字变形、纹理断裂、边缘假锐化，那基本就可以判定不是可靠的原生高分辨率输出。

### 3.2 看边缘和线条

传统插值放大最容易暴露在边缘。

比如：

```text
窗框
电线
眼镜框
产品轮廓
衣服缝线
建筑直线
```

低分辨率插值到 4K 后，边缘会变成：

```text
发虚
重影
毛刺
边缘一圈灰
线条粗细不均
```

AI 超分会更狡猾。

它会把边缘画得很锐。

但问题是锐得不自然。

典型表现：

```text
转角处过硬。
曲线变成折线。
细线断断续续。
边缘像贴了一圈描边。
局部锐，局部糊。
```

如果你看到一张“4K 海报”整体很亮很锐，但细看 logo、衣服线头、发丝都像被重新描了一遍，这种就很可疑。

### 3.3 看皮肤和衣服

人物图最容易看穿。

原生高分辨率的人像，皮肤不是完全平的。

会有：

```text
毛孔
细小纹理
肤色过渡
微小瑕疵
局部暗噪点
```

低分辨率超分后常见问题：

```text
皮肤像磨皮过度。
毛孔变成随机斑点。
雀斑被连成奇怪线条。
眼睫毛粘在一起。
头发发丝变成一团笔刷。
衣服纤维像油画笔触。
```

这类问题在 100% 缩放时不明显。

放到 300% 后很明显。

## 4. 第二层：找 AI 超分的穿帮痕迹

AI 超分不是还原。

它是补全。

换句话说：

```text
低分辨率里没有的信息，AI 只能猜。
```

猜得好，看起来很清楚。

猜错了，就会穿帮。

### 4.1 看小字和符号

最强的验货点是文字。

包括：

```text
远处路牌
衣服标签
包装说明
报纸文字
手机界面
电脑屏幕
墙上海报
商品 logo
```

原生高分辨率里的小字，即使模糊，也是自然模糊。

你会感觉它确实被光学系统拍糊了。

AI 超分的小字经常是：

```text
像字但不是字。
像英文但拼不出来。
像中文但结构怪。
笔画互相粘连。
标点位置不合理。
重复出现神秘符号。
```

这就是典型的“脑补痕迹”。

如果一个中转站声称图片模型文字能力很强，你可以直接用文字验货。

提示词可以这样写：

```text
生成一张 4K 写实街景照片，画面里有一个咖啡馆门头，招牌清晰写着 "FOUR SAPI IMAGE TEST"，旁边有价格牌，价格牌写着 "$12.80"，远处还有一个公交站牌，站牌上写着 "ROUTE 42"。
```

生成后看三处：

```text
门头大字
价格牌中号字
远处站牌小字
```

真正可用的高质量图片模型，至少大字和中号字不能乱。

如果全都变成乱码，再怎么标 4K 都没意义。

### 4.2 看重复纹理

重复纹理是 AI 超分的另一个弱点。

重点看：

```text
百叶窗
砖墙
瓷砖
织物
网格
头发
动物毛发
草地
树叶
键盘
电路线
```

原生高分辨率里，重复纹理会有自然变化。

但结构是连续的。

AI 超分常见问题：

```text
纹理突然断开。
砖缝对不上。
窗格一段粗一段细。
衣服纤维方向乱跳。
毛发一片清楚一片糊。
草地像重复贴图。
```

这类问题非常适合做模型横评。

同一个 prompt，用 4SAPI 里你要测的图片模型跑一张，再用可疑中转站跑一张。

不要只看哪张更“震撼”。

放大看纹理连续性。

### 4.3 看无中生有的细节

AI 超分会补细节。

补得过头，就会出现奇怪东西：

```text
树叶阴影变成文字。
墙面污渍变成符号。
皮肤斑点连成线。
产品边缘多出螺丝。
布料褶皱变成花纹。
头发里长出奇怪分叉。
```

这类细节不是“高分辨率”。

是算法想象。

如果你做电商图，这尤其危险。

因为它可能把产品真实结构改掉。

所以商品图、服装图、硬件图，不要只追求清晰。

要追求真实。

## 5. 第三层：用验货 prompt 专门刁难它

很多人测图片模型，只写：

```text
生成一张赛博朋克美女。
生成一张猫。
生成一张电影感海报。
```

这种 prompt 不适合验货。

因为它太宽松。

你要专门设计“容易穿帮”的 prompt。

### 5.1 文字验货 prompt

```text
生成一张写实 4K 产品海报，一瓶透明玻璃饮料放在桌上，瓶身标签清晰写着 "4SAPI IMAGE MODEL TEST"，下方小字写着 "Native detail check, not upscaled"，桌面旁边有一张收据，收据上有三行小字和一个二维码。
```

检查点：

```text
主标签是否清楚。
小字是否变形。
二维码是否变成随机格子。
瓶身边缘是否有假锐化。
```

### 5.2 纹理验货 prompt

```text
生成一张 4K 写实服装细节图，深灰色羊毛外套挂在木椅上，袖口有密集织物纤维，旁边有一条蓝白条纹围巾，背景是砖墙和百叶窗，浅景深但主体清晰。
```

检查点：

```text
袖口纤维有没有方向。
围巾条纹有没有断裂。
砖墙缝隙是否连续。
百叶窗线条是否平直。
```

### 5.3 人像验货 prompt

```text
生成一张 4K 写实半身人像，人物站在窗边自然光下，皮肤保留真实纹理，头发有细发丝，穿棉麻衬衫，胸前有一个小胸牌，上面写着 "QA-2048"。
```

检查点：

```text
皮肤是不是塑料。
头发是不是笔刷团。
胸牌文字是否能读。
衣服纤维是否自然。
```

### 5.4 建筑验货 prompt

```text
生成一张 4K 写实城市街景，正面有一栋玻璃幕墙建筑，窗格整齐，远处有路牌和电线，街角咖啡店招牌写着 "MODEL CHECK"，画面保持自然摄影质感。
```

检查点：

```text
窗格是否变形。
电线是否断裂。
远处路牌是否乱字。
玻璃反射是否过度锐化。
```

这类 prompt 用来测中转站是否掺水，比“好不好看”更有效。

## 6. 第四层：FFT 频域分析

如果你想更科学一点，可以做频域分析。

原理很简单：

```text
图像里的细节，本质上对应高频信息。
原生高分辨率图，频谱会从中心向四周自然衰减。
低分辨率放大图，高频信息本来缺失，频谱容易出现断层、边界框或异常条纹。
```

这不是魔法。

也不是 100% 判定器。

但它能帮你发现“肉眼看着很锐，其实高频不自然”的图。

### 6.1 用 Python 生成频谱图

准备环境：

```bash
pip install opencv-python numpy matplotlib
```

保存下面脚本为 `fft_spectrum.py`：

```python
import argparse
from pathlib import Path

import cv2
import matplotlib.pyplot as plt
import numpy as np


def save_spectrum(input_path: str, output_path: str) -> None:
    img = cv2.imread(input_path, cv2.IMREAD_GRAYSCALE)
    if img is None:
        raise SystemExit(f"Cannot read image: {input_path}")

    # Reduce border influence a little, then analyze the frequency distribution.
    h, w = img.shape[:2]
    y0, y1 = int(h * 0.05), int(h * 0.95)
    x0, x1 = int(w * 0.05), int(w * 0.95)
    crop = img[y0:y1, x0:x1]

    fft = np.fft.fft2(crop)
    fft_shift = np.fft.fftshift(fft)
    magnitude = 20 * np.log(np.abs(fft_shift) + 1)

    magnitude = cv2.normalize(magnitude, None, 0, 255, cv2.NORM_MINMAX)
    magnitude = magnitude.astype(np.uint8)

    Path(output_path).parent.mkdir(parents=True, exist_ok=True)
    plt.imsave(output_path, magnitude, cmap="gray")


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("input")
    parser.add_argument("output")
    args = parser.parse_args()
    save_spectrum(args.input, args.output)
```

运行：

```bash
python fft_spectrum.py suspect.png suspect_fft.png
python fft_spectrum.py reference.png reference_fft.png
```

你要看的是：

```text
频谱是否从中心自然衰减。
四周高频区域是否突然断掉。
有没有明显方框边界。
有没有不自然的十字亮线。
有没有周期性条纹。
```

### 6.2 频谱图怎么读

原生高分辨率图：

```text
中心亮。
越往外越暗。
衰减自然。
四周仍有细碎高频能量。
没有特别突兀的边界框。
```

插值放大图：

```text
高频区域明显空。
边界比较干。
细节能量断层明显。
有时会出现规则条纹。
```

AI 超分图：

```text
高频可能被补亮。
但分布不自然。
某些方向异常强。
边缘锐化导致亮线过硬。
纹理区域出现周期性噪声。
```

注意：

FFT 不是单张图定罪工具。

它适合做对比：

```text
同 prompt。
同尺寸。
同格式。
同压缩条件。
多张样本。
一起看趋势。
```

如果某个中转站的 4K 图，频谱长期像低分辨率放大，而 4SAPI 里同类模型输出的频谱更自然，那就值得警惕。

## 7. 第五层：NIQE / BRISQUE / PIQE 盲评

除了 FFT，还可以用无参考图像质量评价工具。

常见指标：

```text
NIQE
BRISQUE
PIQE
```

它们不需要原图参考。

会从自然图像统计特征、失真特征、局部质量等角度给图片打分。

一般来说：

```text
分数越低，感知质量越好。
```

但要注意：

这些指标不是“真假 4K 检测器”。

它们更适合回答：

```text
这张图是否符合自然图像统计规律？
这批图有没有明显质量异常？
同一类 prompt 下，哪个渠道输出更稳定？
```

不要拿单张图的 NIQE 分数直接说：

```text
这一定是假的。
```

更合理的用法是：

```text
同一组 prompt 跑 30 张。
每张图裁 5 个局部区域。
分别计算 NIQE / BRISQUE / PIQE。
看均值、方差和异常点。
```

如果某个渠道的图片：

```text
肉眼有油画感。
文字经常变形。
FFT 高频断层明显。
IQA 分数也长期异常。
```

这就不是“审美差异”了。

这是质量证据链。

## 8. 用 4SAPI 建一套图片模型验收流程

如果你是个人创作者，看到这里已经够用了。

但如果你是团队，建议把验货流程制度化。

不要每次靠感觉。

可以这样做：

```text
1. 在 4SAPI 后台创建图片验收专用 Key。
2. 从 4SAPI 模型广场复制图片模型名。
3. 准备 20-30 条验货 prompt。
4. 每个 prompt 输出小样和终稿各一张。
5. 保存原始文件，不经过微信、飞书、图床二次压缩。
6. 记录模型名、时间、尺寸、成本、参数。
7. 对可疑中转站用同样 prompt 跑一遍。
8. 统一裁剪局部区域做肉眼、FFT、IQA 检查。
9. 给每个渠道打验收分。
10. 只把通过验收的模型放进生产 Key。
```

4SAPI 在这里的价值很明确：

```text
统一 Base URL。
统一 API Key。
统一模型名称。
统一调用日志。
统一成本统计。
统一团队权限。
```

你不是在盲测一个黑箱网页。

你是在建立一套可复盘的图片模型采购和生产流程。

### 8.1 推荐验收表

可以建一张表：

```text
样本编号
prompt 类型
模型名
渠道
输出尺寸
文件格式
文件大小
文字可读性
纹理连续性
边缘自然度
皮肤/材质自然度
FFT 异常
IQA 分数
4SAPI 调用成本
人工结论
```

评分建议：

```text
文字可读性：0-5
纹理连续性：0-5
边缘自然度：0-5
材质自然度：0-5
频域健康度：0-5
```

总分不是为了绝对排名。

而是为了发现：

```text
哪个模型适合海报。
哪个模型适合商品图。
哪个模型适合人物图。
哪个模型只适合小样。
哪个渠道疑似用低清放大。
```

### 8.2 小样和终稿一定要拆 Key

图片模型很容易烧钱。

很多团队最大的问题不是模型贵。

而是不知道钱花在哪。

建议在 4SAPI 里拆成：

```text
image-preview-key：只跑低成本小样。
image-final-key：只跑通过人工审批的终稿。
image-test-key：只跑模型验收。
image-batch-key：只跑批量素材。
```

这样你能在 4SAPI 后台看清楚：

```text
哪类图最耗钱。
哪位成员重试最多。
哪个模型通过率低。
哪个渠道需要淘汰。
```

这比月底看一张总账单有用多了。

## 9. 采购图片模型时怎么问供应商

如果你在评估一个中转站，不要只问：

```text
支不支持 4K？
多少钱一张？
速度快不快？
```

这些回答都太容易包装。

应该问：

```text
返回的图片是模型原生尺寸，还是经过后处理放大？
如果有超分，是否单独标注？
不同质量档是否价格不同？
是否能返回原始生成文件？
是否有调用日志？
是否能看到真实模型名？
是否能按 Key / 项目 / 成员统计成本？
是否会经过 CDN 二次压缩？
是否支持失败重试和异常追踪？
```

如果对方只反复说“我们很清晰”“我们是 4K”，但不给模型名、日志、参数和原图文件，那就要谨慎。

4SAPI 这类中转站适合作为对照样本库。

你可以先用 4SAPI 的图片模型生成一批可复盘样本，再去横向评估其他渠道。

这样你有基准，不会被单张精修样例带节奏。

## 10. 常见误判：这些不一定是掺水

不要把所有问题都归因于中转站掺水。

有些情况是正常的。

### 10.1 风格本来就平滑

插画、二次元、矢量风、3D 渲染，本来就可能没有自然噪点。

这类图不能用“有没有颗粒”作为主要标准。

应该看：

```text
线条是否干净。
边缘是否一致。
文字是否准确。
局部结构是否稳定。
```

### 10.2 模型原生就是 AI 图

AI 生成图不是相机拍出来的。

它不一定符合真实摄影的噪声规律。

所以 FFT 和 IQA 只能辅助判断。

不能直接把“太干净”当作假 4K。

### 10.3 平台压缩会破坏细节

微信、飞书、网页预览、图床、CMS 都可能压缩图片。

验货一定要用原始下载文件。

不要用聊天软件里转发过的图。

### 10.4 Prompt 本身没要求细节

如果 prompt 写得很泛：

```text
生成一张漂亮海报。
生成一张高级感图片。
```

模型自然可能把细节省略掉。

验货 prompt 必须明确要求：

```text
文字
纹理
材质
边缘
远近层次
可读符号
```

## 11. 快速排查口诀

如果不想跑工具，先记这三句：

```text
一看文字有没有变形。
二看皮肤衣服是不是油画。
三看细线边缘有没有发虚和重影。
```

再加两句：

```text
四看重复纹理有没有断裂。
五看 4SAPI 日志能不能对上模型和成本。
```

如果一张所谓 4K 图片：

```text
小字像乱码。
皮肤像塑料。
衣服像油画。
窗格断断续续。
边缘像被描边。
频谱图高频断层明显。
```

那它大概率不是可靠的原生高分辨率输出。

如果它还按高质量 4K 收费，就更要谨慎。

## 12. 最小验收清单

每次测图片模型，可以按这张表走：

```text
[ ] 已保存原始图片文件
[ ] 已确认图片没有被聊天软件或图床二次压缩
[ ] 已记录渠道、模型名、时间、参数
[ ] 已在 4SAPI 后台创建图片验收 Key
[ ] 已用同一组 prompt 跑 4SAPI 对照样本
[ ] 已放大到 200% / 400% 看文字
[ ] 已检查皮肤、衣服、头发、建筑、纹理
[ ] 已检查边缘是否发虚、重影、假锐化
[ ] 已裁剪局部区域做 FFT 频域图
[ ] 已做 NIQE / BRISQUE / PIQE 批量对比
[ ] 已区分小样、终稿、批量生成的成本
[ ] 已把合格模型放进生产 Key，不合格模型只做测试
```

这套流程看起来麻烦。

但只要做过一次，后面就很快。

尤其是团队场景，千万不要让每个人自己找图片模型、自己充钱、自己判断清晰不清晰。

最后一定会乱。

用 4SAPI 统一入口，再配一套验货清单，才是真正能生产的方式。

## 13. 最后总结

图片模型是否“掺水”，不能只看分辨率。

真正要看：

```text
细节密度。
文字可读性。
纹理连续性。
边缘自然度。
频域分布。
批量稳定性。
调用日志和成本记录。
```

一张图写着 4K，不代表它真的有 4K 细节。

一个中转站写着高清，也不代表它没有后处理放大。

对个人用户来说，最实用的方法是：

```text
放大看小字、纹理、边缘。
```

对团队来说，更稳的方式是：

```text
用 4SAPI 建图片模型验收 Key。
用同一组 prompt 做样本库。
用肉眼 + FFT + IQA 做批量对比。
用调用日志和成本记录做复盘。
```

一句话：

```text
别只买“4K”两个字。
要买可追踪、可验收、可复盘的图片模型能力。
```

这也是 4SAPI 最适合图片模型团队化使用的地方：

```text
不是让你盲目相信某个模型。
而是让每一次调用都有证据。
```
