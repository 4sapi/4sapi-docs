# 【大模型API中转站】第142期 文生视频实战 | 从一句话到可剪辑素材

本文是【大模型API中转站】系列的第142篇。本系列致力于用最低的成本、最清晰的方法，帮你打通多模型API的任督二脉。建议先收藏，随用随查。

上一篇我们讲了 Gemini Omni、Omni Video 和第三方 AI 视频工具的避坑。

那篇是总览。

这一篇只讲一件事：

```text
文生视频怎么真正用起来。
```

文生视频就是 Text to Video。

你不给图。

只给文字。

模型根据你的描述生成一段视频。

听起来很简单：

```text
输入一句话。
等几分钟。
下载视频。
```

但真实情况是：

```text
一句话能出画面。
但不一定能出可用素材。
```

文生视频最容易让人兴奋。

也最容易让人浪费积分。

因为它给你的自由度太高。

自由度一高，模型就会自己补细节。

你没说主体长什么样，它会补。

你没说镜头怎么动，它会补。

你没说不要文字，它会补。

你没说品牌边界，它也会补。

最后生成出来的东西可能很炫。

但进剪辑软件一看：

```text
主体不稳定。
动作不合理。
画面漂亮但和选题没关系。
开头能用，结尾崩了。
有奇怪文字。
Logo 变形。
人物脸看着不对。
```

所以先说结论：

```text
文生视频最适合从无到有找方向，不适合直接生成高精度品牌终片。
```

它最适合做：

```text
短视频开场。
概念氛围片。
广告提案样片。
课程封面动效。
PPT 概念视频。
不依赖真实产品的视觉素材。
```

它不适合上来就做：

```text
精确产品广告。
长剧情短剧。
稳定人物口播。
需要准确文字和 Logo 的商业片。
```

如果你要做精确产品、人物、品牌主视觉，下一篇图生视频更适合。

这一篇先把文生视频讲透。

## 1. 文生视频的正确定位

文生视频不是“自动导演”。

它更像：

```text
视觉脑暴机。
短镜头草稿机。
动态氛围素材机。
```

你应该把它用在这些阶段：

```text
项目早期找视觉方向。
内容开头做情绪钩子。
广告提案做快速样片。
社媒视频做背景素材。
剪辑里补一段过场画面。
```

不要把它放在这些阶段：

```text
最终品牌资产确认。
精确产品展示。
严肃教学演示。
合同交付前的唯一素材来源。
```

文生视频最大的价值是快。

它能让你在十几分钟内看见 5 个方向。

以前你要找素材、拍摄、剪辑、调色。

现在你可以先生成一批草稿。

但草稿就是草稿。

要进入生产，还得筛选、剪辑和审查。

## 2. 先写 brief，不要直接写 Prompt

很多人做文生视频的第一步是：

```text
打开工具。
在输入框里写一句话。
点击生成。
```

这不是不行。

但如果你想稳定出片，第一步应该是写 brief。

brief 不是给模型看的漂亮文案。

它是给自己定边界。

一个最小 brief 至少包括：

```text
视频目的。
目标观众。
发布平台。
时长。
画幅。
情绪。
不要出现什么。
是否商用。
```

比如你要做一条 AI 工具短视频开场。

不要直接写：

```text
生成一个科技感视频。
```

先写 brief：

```text
目的：给一条讲 AI 办公自动化的短视频做开场。
观众：自由职业者、运营、产品经理。
平台：小红书和视频号。
画幅：9:16。
时长：5 秒。
情绪：安静、高效、有一点未来感，不要太赛博。
画面：桌面、电脑、任务列表、柔和光线。
禁止：不要出现可读文字，不要出现真实品牌 Logo，不要人脸特写。
```

这个 brief 才是后面所有 Prompt 的根。

没有 brief，文生视频会变成抽奖。

有了 brief，生成失败也能复盘。

## 3. 从一句话到分镜，不要跳步骤

文生视频最稳的路径不是：

```text
一句话 -> 视频
```

而是：

```text
一句话 -> brief -> 分镜 -> Prompt -> 多版本生成 -> 剪辑
```

哪怕你只做 15 秒视频，也建议拆成 3 个镜头。

比如主题是：

```text
AI 帮我整理一天的工作。
```

可以拆成：

| 镜头 | 时长 | 目的 | 画面 |
| --- | --- | --- | --- |
| 1 | 3 秒 | 吸引注意 | 凌乱桌面、消息通知、待办堆叠 |
| 2 | 5 秒 | 展示转变 | AI 界面抽象整理信息流 |
| 3 | 5 秒 | 给出结果 | 干净桌面、清晰日程、晨光氛围 |

每个镜头只承担一个任务。

不要让一个镜头同时完成：

```text
制造焦虑。
展示工具。
解释原理。
给出结果。
品牌露出。
引导关注。
```

AI 视频最怕一个镜头塞太多。

任务越多，越容易崩。

## 4. 文生视频 Prompt 公式

我推荐这个公式：

```text
主体 + 场景 + 动作 + 运镜 + 光线 + 风格 + 时长/比例 + 禁止项
```

展开就是：

```text
主体：画面里的核心对象。
场景：在哪里发生。
动作：主体做什么，或者画面怎么变化。
运镜：镜头推进、拉远、横移、俯拍、环绕。
光线：清晨、夜晚、柔光、逆光、霓虹、自然光。
风格：真实拍摄、电影感、广告片、纪录片、3D、极简。
时长/比例：5秒、10秒、9:16、16:9、1:1。
禁止项：不要文字、不要Logo、不要人脸、不要手部特写。
```

坏 Prompt：

```text
帮我生成一个高级的 AI 工作视频。
```

好 Prompt：

```text
一张深色木质办公桌上摆着打开的笔记本电脑、便签、咖啡杯和几份纸质文件，
桌面一开始略显凌乱，随后文件和便签以轻微动态重新排列成清晰结构，
镜头从俯拍角度缓慢下降到斜侧角度，
清晨窗边自然光，安静、专注、轻科技感，
真实拍摄风格，5 秒，9:16 竖屏，
不要出现可读文字，不要出现品牌 Logo，不要出现人脸和手部特写。
```

这段 Prompt 不一定一次成功。

但它可复盘。

如果失败，你能判断是：

```text
主体太多。
动作太复杂。
镜头变化太大。
禁止项没压住。
```

这就比一句“高级感”强太多。

## 5. 中文 Prompt 还是英文 Prompt

很多视频模型对英文 Prompt 更稳定。

但中文 Prompt 也不是不能用。

我的建议是：

```text
中文用来思考。
英文用来生成。
```

流程可以这样：

```text
先用中文写 brief。
再用 4SAPI 调文本模型扩成中文分镜。
再翻译成英文视频 Prompt。
最后人工检查英文里有没有加戏。
```

比如中文：

```text
一个独立开发者深夜看着电脑屏幕，待办任务像光点一样聚拢成一个清晰路线图。
```

英文可以写：

```text
A solo developer sitting at a desk late at night, facing a laptop screen.
Abstract task cards and glowing dots slowly gather into a clean roadmap structure on the screen,
subtle camera push-in from behind the shoulder,
soft blue desk light and warm ambient background,
cinematic realistic style, 5 seconds, 16:9,
no readable text, no brand logos, no close-up face, no extra people.
```

重点不是英文多高级。

重点是它更具体。

## 6. 五类文生视频模板

下面给你几类可以直接改的模板。

### 模板一：短视频开场钩子

适合知识类、AI 工具类、办公效率类视频。

```text
一个现代办公桌场景，桌面上有电脑、便签、文件和咖啡杯，
画面从凌乱的信息流逐渐变得有序，
镜头缓慢推进到电脑屏幕前，
柔和清晨自然光，安静、高效、轻科技感，
真实拍摄风格，5 秒，9:16，
不要出现可读文字，不要出现品牌 Logo，不要人脸。
```

适用标题：

```text
我用 AI 接管了每天早上的工作整理。
为什么你的 AI 工作流越用越乱？
普通人怎么搭自己的自动化助手？
```

### 模板二：商业提案概念片

适合 PPT、路演、产品方案。

```text
一座现代城市的夜景，许多发光数据线从不同建筑中延伸出来，
逐渐汇聚到城市中心的透明控制台，
镜头从高空缓慢下降，最后停在控制台前方，
蓝白色科技光效，干净、克制、企业级视觉风格，
5 秒，16:9，
不要出现具体公司 Logo，不要出现可读文字，不要出现人物。
```

这类视频不需要真实品牌。

它只负责制造“这是一个系统”的感觉。

### 模板三：产品氛围广告

适合还没有真实产品素材时做概念样片。

```text
一款极简黑色智能硬件放在浅灰色石材台面上，
设备边缘有柔和高光流动，背景是模糊的现代家居空间，
镜头从左侧缓慢横移到正面，
自然晨光，干净高级的产品广告风格，
5 秒，16:9，
不要出现文字，不要出现品牌 Logo，不要出现人物手部。
```

注意，这适合概念。

如果你要展示真实产品，就不要用文生视频。

用图生视频。

### 模板四：知识科普背景

适合当 B-roll。

```text
抽象的神经网络节点在深色背景中缓慢连接，
光点沿着线条流动，形成一个清晰但不过度复杂的网络结构，
镜头轻微推进，画面稳定，
深色背景，蓝绿色柔和光效，科技科普风格，
5 秒，16:9，
不要出现文字，不要出现图标，不要出现人脸。
```

这类素材可以放在解说视频里。

不要让它承担太多信息。

### 模板五：情绪过场

适合剪辑里连接两个段落。

```text
雨夜的城市街道，地面反射柔和霓虹灯，
镜头贴近地面缓慢向前移动，雨滴轻轻落下，
氛围安静、冷静、有思考感，
电影感真实拍摄风格，4 秒，16:9，
不要出现可读文字，不要出现车牌，不要出现人物正脸。
```

过场素材越简单越好。

它不需要讲故事。

它只需要让观众情绪过渡。

## 7. 通过 4SAPI 先生成分镜和 Prompt

如果你是一个人手动做，直接写 Prompt 也可以。

但如果你是团队，建议把 Prompt 生成流程固定下来。

4SAPI 在这里的作用不是替你生成视频画面。

它更适合做：

```text
脚本生成。
分镜拆解。
Prompt 翻译。
风险词审查。
成本记录。
```

一个简单流程：

```text
运营输入 brief
  -> 4SAPI 调模型生成 3 个脚本方向
  -> 人选 1 个方向
  -> 4SAPI 拆成 3-5 个镜头
  -> 4SAPI 生成中英文 Prompt
  -> 人工检查
  -> 视频工具生成
  -> 结果回填表格
```

如果你的 4SAPI 入口兼容 OpenAI SDK，可以这样跑一个最小测试。

实际 Base URL、模型名和参数，以 4SAPI 后台当前文档为准。

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FOURSAPI_API_KEY"],
    base_url="https://api.4sapi.com/v1",
)

brief = """
我要做一条15秒竖屏短视频，主题是：普通人如何用AI整理每天的工作。
受众：运营、自由职业者、产品经理。
风格：真实拍摄、安静、高效、轻科技感。
限制：不要夸大效果，不要出现具体品牌Logo，不要出现可读文字。
请拆成3个镜头，每个镜头给中文Prompt、英文Prompt、禁止项和验货重点。
"""

resp = client.chat.completions.create(
    model="<从4SAPI模型广场复制模型名>",
    messages=[
        {
            "role": "system",
            "content": "你是AI视频分镜导演，擅长把短视频brief拆成可生成的文生视频Prompt。",
        },
        {"role": "user", "content": brief},
    ],
)

print(resp.choices[0].message.content)
```

输出建议固定成表格：

| 字段 | 说明 |
| --- | --- |
| 镜头编号 | 1、2、3 |
| 时长 | 3-5 秒 |
| 画面目的 | 吸引注意、展示问题、给出结果 |
| 中文 Prompt | 给团队理解 |
| 英文 Prompt | 给视频模型生成 |
| 禁止项 | 不要文字、不要 Logo、不要人脸 |
| 验货重点 | 看哪里最容易崩 |

这样做的好处是：

```text
Prompt 不再散落在聊天窗口。
每个镜头为什么这么写，有记录。
失败了能回到具体字段修。
团队换人也能接着做。
```

## 8. 每个镜头默认生成几版

文生视频不要指望一次成。

我的建议：

```text
每个镜头先生成 3 版。
如果 3 版里有 1 版能用，停。
如果 3 版都不行，改 Prompt。
同一个 Prompt 最多生成 5 版。
```

不要一个 Prompt 失败 10 次还继续烧。

那通常不是运气问题。

而是 Prompt 或画面设计不适合当前模型。

需要改：

```text
减少主体。
减少动作。
缩短时长。
降低镜头运动。
去掉文字。
换更简单的场景。
```

例如原 Prompt：

```text
一个人走进办公室，打开电脑，屏幕上出现复杂项目看板，镜头环绕人物一圈，最后所有任务自动完成。
```

可以拆成三个镜头：

```text
镜头1：空办公室桌面，电脑亮起。
镜头2：抽象任务卡片在屏幕上排列，不出现可读文字。
镜头3：干净桌面和清晨光线，表现工作被整理好。
```

拆开以后，成功率会高很多。

## 9. 文生视频验货标准

生成完不要只看第一眼漂不漂亮。

按这张表看：

| 检查项 | 合格标准 | 常见问题 |
| --- | --- | --- |
| 开头 | 第一秒能接上剪辑 | 一开始就乱闪、主体不明确 |
| 主体 | 画面核心清楚 | 主体变形、凭空多出物体 |
| 运动 | 动作自然、镜头稳定 | 漂浮、穿模、镜头抽动 |
| 文字 | 没有乱码文字 | 背景出现奇怪字母 |
| Logo | 没有未授权标识 | 模型瞎生成品牌 |
| 结尾 | 最后一秒还能剪 | 结尾崩坏、主体融化 |
| 风格 | 和视频主题一致 | 过度赛博、过度卡通、太像素材库 |
| 可用性 | 能剪进成片 | 漂亮但和内容无关 |

如果只是做背景 B-roll，可以放宽一点。

如果要做商业广告开头，就要严格。

尤其要看：

```text
文字。
Logo。
人物脸。
手部。
产品形状。
```

这些是最容易出问题的地方。

## 10. 常见失败原因

### 失败一：画面太复杂

一段 5 秒视频里要求太多东西：

```text
人物、产品、城市、屏幕、文字、镜头环绕、爆炸光效。
```

模型很容易顾不过来。

解决办法：

```text
一个镜头只留一个主体。
一个镜头只做一个动作。
```

### 失败二：要求生成准确文字

文生视频里的文字非常容易乱码。

解决办法：

```text
视频里不要生成文字。
字幕、标题、按钮文案全部后期加。
```

Prompt 里写：

```text
no readable text
no subtitles
no logos
```

### 失败三：人物动作太细

比如：

```text
手指快速敲键盘。
拿起产品并旋转。
对着镜头说话。
做复杂手势。
```

这些都容易崩。

解决办法：

```text
避开手部特写。
避开口型。
用背影、侧影、空镜、抽象画面代替。
```

### 失败四：镜头运动太猛

环绕、俯冲、快速推进、复杂转场，都容易让画面变形。

解决办法：

```text
slow push-in
slow pan
static shot
subtle camera movement
```

慢就是稳。

### 失败五：风格词互相打架

比如你同时写：

```text
真实拍摄、3D卡通、赛博朋克、水墨、极简商务。
```

模型不知道听谁的。

解决办法：

```text
一个镜头只保留一种主风格。
```

## 11. 成本控制：按“可用素材”算账

文生视频不是按生成次数算成本。

而是按可用素材算成本。

你可以用这个公式：

```text
可用素材成本 = 总生成成本 / 可用素材数量
```

比如：

```text
生成 20 条。
每条 2 元。
总成本 40 元。
最后 5 条能用。
可用素材成本 = 8 元/条。
```

这比“单条生成 2 元”更真实。

团队里建议记录：

```text
项目。
镜头。
Prompt版本。
生成工具。
生成次数。
可用次数。
失败原因。
最终是否发布。
```

4SAPI 可以记录脚本、Prompt 和文本模型调用成本。

视频平台记录视频生成成本。

两边合起来，才是真实内容成本。

## 12. 一个完整案例：15秒AI办公短视频

假设我们要做一条短视频：

```text
主题：AI 帮普通人整理每天的工作。
平台：小红书。
时长：15 秒。
风格：真实拍摄、安静、高效。
```

### 镜头1：问题出现

```text
凌乱的现代办公桌，电脑旁边散落着便签、文件和手机通知光点，
画面表现信息过载和工作堆积，
镜头从桌面上方缓慢下降，
清晨偏冷的自然光，真实拍摄风格，
4 秒，9:16，
不要出现可读文字，不要出现品牌 Logo，不要人脸。
```

### 镜头2：AI整理

```text
电脑屏幕前方出现抽象的半透明任务卡片和发光线条，
这些信息流从混乱状态逐渐排列成清晰的三列结构，
镜头轻微推进，画面稳定，
柔和蓝白色光效，现代科技感但不过度赛博，
5 秒，9:16，
不要出现可读文字，不要出现真实软件界面，不要出现品牌 Logo。
```

### 镜头3：结果变清楚

```text
同一张办公桌变得干净有序，电脑、笔记本和咖啡杯整齐摆放，
窗外阳光洒进来，画面有轻微尘埃和柔和高光，
镜头缓慢从侧面推进，
安静、高效、积极的早晨氛围，真实拍摄风格，
5 秒，9:16，
不要出现可读文字，不要出现品牌 Logo，不要人物特写。
```

剪辑时再加：

```text
标题。
字幕。
配音。
音乐。

CTA。
```

不要让视频模型生成这些文字。

它负责画面。

后期负责信息。

## 13. 文生视频发布前清单

```text
[ ] 已写 brief，不是直接一句话生成
[ ] 已拆成 3-5 个短镜头
[ ] 每个镜头只有一个主体和一个动作
[ ] 已明确画幅和时长
[ ] Prompt 里写了不要文字、不要 Logo、不要人脸等限制
[ ] 每个镜头生成 3 版以上
[ ] 同一个 Prompt 失败 5 次后已停止硬刷
[ ] 已记录 Prompt、工具、生成次数和失败原因
[ ] 已检查画面里没有乱码和侵权元素
[ ] 字幕、标题和 Logo 都放到剪辑软件里做
[ ] 团队项目已在 4SAPI 或内部表格记录脚本、Prompt、审查和成本
```

## 14. 总结

文生视频不是万能。

但它非常适合从无到有。

你没有素材。

你只有一个想法。

这时候它可以帮你快速看到画面。

但要记住：

```text
不要一句话直冲生成。
先 brief。
再分镜。
再 Prompt。
再多版本。
再剪辑。
再复盘。
```

个人用户可以把它当作灵感素材机。

团队用户要把它纳入流程：

```text
4SAPI 管脚本、分镜、Prompt、审查和日志。
视频工具管画面生成。
剪辑工具管最终表达。
```

文生视频真正的价值，不是让你少想。

而是让你更快验证想法。

那才是做产品、人物、品牌和商业素材时更稳的一条路。
