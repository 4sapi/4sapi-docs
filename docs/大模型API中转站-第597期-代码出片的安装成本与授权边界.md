# 代码出片工具上手前要算清的三笔账：环境、耗时与授权

开源项目 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) 让编程 Agent 用代码做短片：66 种现成风格，每支片子的画面、配乐、混音都由代码生成。它在 2026 年 9 月下旬创建，检索 2026-10-29 时约 9,100 星、1,000 余次 fork。

装起来只需要两条命令，但"装上"和"能用于自己的业务"之间隔着三笔账：**运行环境、时间与 token 成本、授权边界**。这篇把三笔账逐项算清，适合正在评估要不要在团队里用这类工具的人。来源为项目 README 与技术文档。

## 第一笔账：运行环境

### 系统要求

| 项目 | 要求 |
| --- | --- |
| Node | 20 及以上 |
| ffmpeg | 需要，用于封装与响度处理 |
| Python | 3.11 及以上，或使用 uv |
| 操作系统 | 开发环境为 macOS（Apple 芯片）；Linux 应该可用；**Windows 需通过 WSL** |
| GPU | 3D 与重着色器风格需要 |
| 配音层的 Python 版本 | kokoro-onnx 需要 Python 3.11–3.13 |

Windows 那一条要特别注意。项目的构建脚本是 shell 脚本，路径也按类 Unix 写法组织，直接在 Windows 原生环境里跑会遇到各种路径与权限问题。先装好 WSL，再在 WSL 里装 Node、ffmpeg 和 Python，是最省事的路。

### 两种安装方式

方式一，装成 Claude Code 插件（项目推荐）：

```sh
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
```

第一次使用时，指南、工具和风格提示词会下载到用户目录下的 `~/lemo-opuscar`，所有片子共用这一份。每支片子的工程放在你发起时所在的文件夹里。

方式二，直接克隆仓库：

```sh
git clone https://github.com/lemomo-ai/lemo-opuscar.git
cd lemo-opuscar
claude
```

片子会做在仓库的 `films/<名字>/` 目录下，这个目录被 git 忽略。

其他 Agent 可以把插件里的 skill 目录复制到自己的 skills 目录使用，但项目明确说明：**风格是按特定模型调出来的，其他模型适配度不高**。这一点在评估阶段就要考虑进去。

### 依赖按需分层下载

依赖不是一次全装，而是按片子需要分层装：

| 层 | 内容 | 体积 |
| --- | --- | --- |
| 核心层 | npm 包、无头浏览器、Python 虚拟环境（numpy、scipy、soundfile、soxr、pillow） | 约 350 MB |
| 配音层 | Kokoro 及模型（英文、离线）、edge-tts（中文、联网）、faster-whisper（配音回检） | 约 0.55 GB，首次回检另需一个 Whisper 模型（英文约 145 MB，中文约 480 MB） |
| 音乐层 | numba，用于拨弦乐器的物理建模 | 约 140 MB |
| 乐器采样库 | 五种免费采样库，可单独下载或全部下载 | 每个 70–400 MB |
| HDRI | 3D 风格用的环境光贴图 | 12 MB |

来源：[TECHNIQUE.md](https://github.com/lemomo-ai/lemo-opuscar/blob/main/TECHNIQUE.md)。

两个容易踩的点：解压采样包需要约两倍于包体的空闲空间；下载源包括 npm、PyPI、GitHub Releases 与 Hugging Face，网络受限的环境可以用 `HF_ENDPOINT` 设置镜像。

### 中文配音的网络依赖

这是中文用户最需要提前知道的一条：**好听的中文配音默认走 edge-tts，需要联网**。离线时 Kokoro 也能读中文，但文档的原话是"听起来比较平"。如果你的工作环境不能访问外网，中文配音要么接受离线音质，要么自己准备录音。

## 第二笔账：时间与 token

| 项目 | 数值 |
| --- | --- |
| 单支片子耗时 | 约 30–60 分钟（由 Agent 完成） |
| token 用量 | README 写明"不小" |
| 默认片长 | 30–60 秒 |
| 超过两三分钟 | 时间和 token 成本会成倍增加 |
| 默认输出 | 1920×1080、24 fps |

30 到 60 分钟这个数字要放在流程里理解。Agent 要写分镜脚本、出风格图、做配音并逐句回检、写配乐、写动画、混音、渲染，最后还要自检一轮。每一步都在消耗 token。

评估成本时可以按这个顺序估：

1. 先用默认的 30 秒片长做一支，记录实际耗时与 token；
2. 再做一支 60 秒的，看成本是否接近线性；
3. 如果要做系列内容，算一下每周产出数量乘以单支成本。

### 交付物有哪些

一支片子做完，项目文件夹里会有一套完整交付物：

| 文件 | 内容 |
| --- | --- |
| `<名字>.mp4` | 成片，约 −14 LUFS |
| `poster.jpg` | 海报图 |
| `<名字>.srt` | 有旁白、对白或字幕时提供 |
| `TREATMENT.md` | 分镜脚本 |
| `CREDITS` | 片中用到的所有第三方素材及其来源与授权 |
| 源码与 `build.sh` | 一条命令即可重建整支片子 |

最后一项很有价值：任何一处要改，都可以改代码后一条命令重渲，不需要从头再让 Agent 做一遍。

## 第三笔账：授权边界

这是最容易被忽视、也最影响商用的一笔账。项目把不同部分放在了不同的授权下：

| 对象 | 授权 | 要点 |
| --- | --- | --- |
| 代码和文档 | MIT | 可以自由使用、修改、商用 |
| 样片视频及其静帧 | CC BY 4.0 | 可以转载、改编、商用，但必须署名并附仓库链接，改动过的要注明 |
| **你用本库做出的片子** | 归你自己 | 无须署名 |
| 样片中的第三方素材 | 沿用各自授权 | 见各样片的 `CREDITS` |
| 三段特定配音 | **不在 CC BY 4.0 范围内** | 分别来自 macOS 系统语音、微软 Edge TTS 和另一家商用 TTS，项目要求不要复用 |

几个容易误读的地方：

**"样片可以商用"不等于"样片里的一切都可以商用"。** 样片里的第三方素材、那三段配音，各有各的授权。直接拿样片剪进自己的作品，要先逐项看 `CREDITS`。

**自己做的片子不需要署名，但素材责任在你。** README 写得很清楚：你在自己片子里使用的素材由你负责。

**素材白名单很窄。** 技术文档规定只用 CC0、CC BY 或 OFL 授权的素材；"没有已知限制"不算公有领域。数据或图片采用其他开放协议（如 ODbL、CC BY-SA）时，要先向用户说明协议条款并取得同意。

**字体要单独下载。** 风格文件里点名的字体不在库里，需要从 Google Fonts 下载到项目的 `fonts/` 目录；库里自带的中文展示字体只有约 200 个字形，不够排正文。中文片要按实际用到的字做字体子集。

### 导演指南里的版权红线

除了素材授权，项目给 Agent 的导演指南里还有三条版权红线：

1. **参考作品只学语法。** 不复制角色、设计、旋律、镜头、标志或字体设计。
2. **已有作品、游戏、品牌或事件不出现在片中**，除非用户拥有或有权使用。用户提供的 logo、照片、素材，用户说有权使用才用，否则画虚构的替代品。
3. **部分样片是对真实事件或角色的非官方致敬片**。可以保留风格，但不能把那些名字、标志或角色带进用户的片子。

第三条很容易被忽略。看到一支喜欢的样片，直接说"照这个做一支"，可能会把原样片里的真实品牌或角色也带进来。

## 一张评估清单

把三笔账合在一起，评估这类工具能不能进团队，可以按这张表逐项打勾：

| 问题 | 通过标准 |
| --- | --- |
| 团队机器是 macOS / Linux，或已装好 WSL | 是 |
| 团队使用的 Agent 与风格调校所用的模型一致 | 是，或接受效果不保证 |
| 中文配音场景能访问外网 | 是，或接受离线音质，或自带录音 |
| 单支片子 30–60 分钟、token 用量可接受 | 已用一支实测确认 |
| 素材全部来自 CC0、CC BY、OFL 或自有 | 是 |
| 交付前检查 `CREDITS` 与字体授权 | 已纳入流程 |
| 不直接复用样片里的第三方素材和那三段配音 | 已告知团队 |

## 卸载与更新

更新插件后重启 Claude Code，库会在下次做片时自动更新：

```sh
claude plugin marketplace update lemolab && claude plugin update lemo-opuscar@lemolab
```

卸载：

```sh
claude plugin uninstall lemo-opuscar@lemolab
```

卸载后要手动删除 `~/lemo-opuscar`。自己存的风格放在 `~/lemo-my-styles/`，更新和卸载都不会删，不需要了要自己删。

## 限制与结论

需要说明的是：环境要求、体积与耗时都是项目文档给出的数字，实际会因机器配置、网络与片子复杂度而变化；授权部分是对项目声明的整理，不构成法律意见，具体商用请结合所在地规定与专业意见。

可以确定的是三笔账的结构：环境上，Windows 必须走 WSL，依赖按需分层，中文配音默认需要联网；成本上，一支 30–60 秒的片子要 Agent 做 30 到 60 分钟；授权上，代码、样片、你自己的片子、第三方素材、个别配音各自适用不同规则。

最务实的做法是先做一支 30 秒的片子，同时记录耗时、token 与 `CREDITS` 里的每一项授权。三样数字都拿到了，再决定要不要把它放进团队的固定流程。
