# AI 海报的几何构图如何变成可执行提示词

有些海报一开始就需要强烈的秩序：人物群像要有主角，警示主题要有压迫感，周年活动要把注意力收回中心，摄影展则需要明确观看边界。只说“加一点几何元素”通常会得到几条漂浮的线和不相关的图形。更可执行的要求是：用什么几何骨架承重，顶点或中心负责什么信息，文字需要避开哪里。

本文处理四种几何构图：三角层级、倒三角悬置、同心环绕和框中框。它们既能用于图像生成，也能直接转为 HTML/CSS 的区域关系。本文不讨论具体绘图模型的能力或版权授权；输入人物、品牌标志和照片的可用范围仍需由使用者确认。

## 几何骨架不是装饰图层

几何构图先决定的是阅读顺序，而不是边框形状。可以先把内容抽成三个层级：

```text
一级：观众必须第一眼看到的标题、人物或符号。
二级：解释一级信息的画面或短句。
三级：日期、地点、署名、二维码等执行信息。
```

然后再选骨架。若一级信息适合站在最高点、三级信息能自然落在底边，三角形会有帮助；若希望上方内容压向一个结论点，才用倒三角；如果重要对象必须被反复强调，用同心环；如果需要把图片、标题和注释分到不同观看层级，使用框中框。

骨架可以在草图和调试版中可见，但最终成品不一定要出现明显的三角线或圆圈。它的任务是约束元素，不是让观众看见辅助线。

## 1. 三角层级：用顶点、侧翼和底边安排主次

三角构图把注意力集中到一个顶点，并让两侧元素向下展开。它常用于人物组合、论坛主视觉和层级明确的发布信息，因为顶点、两条斜边和底边天然形成三段责任：强调、扩展、承载。

### 先定义三个锚点

```text
顶点：核心人物、主标题或一个高对比符号。
两侧：次级人物、图像细节或两个支持性关键词。
底边：日期、地点、主办方、说明和行动信息。
```

顶点不必真的碰到画面顶部。把它放得过高会让标题贴边，也会在小屏上缺少安全区。底边则需要更稳定的阅读背景，尤其不要让小字落在复杂照片和锐利斜线的交界处。

```text
制作一张 3:4 竖版论坛海报，采用稳定的三角层级。
主标题“从工具到工作流”位于上方中轴附近，作为三角顶点；
三位演讲者的轮廓从中部向左右下方展开，主讲人最大，另外两人退后；
底部横向信息带承载日期、地点和报名方式。
视线从标题到主讲人，再沿两侧向下读取执行信息。
三角外不放置高饱和装饰和第二个主标题；人物脸部、姓名和底部信息都保留安全区。
```

HTML 实现不需要把人物切成三角形。可使用 Grid 先固定顶点、两侧和底边的位置：

```css
.poster {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto 1fr auto;
  gap: clamp(12px, 2vw, 28px);
}
.poster__title { grid-column: 2; grid-row: 1; text-align: center; }
.poster__lead { grid-column: 2; grid-row: 2; align-self: start; }
.poster__left { grid-column: 1 / 2; grid-row: 2; align-self: end; }
.poster__right { grid-column: 3 / 4; grid-row: 2; align-self: end; }
.poster__meta { grid-column: 1 / -1; grid-row: 3; }
```

测试时，先隐藏两侧次要元素。如果顶点和底部信息仍能表达主题，说明主次足够清楚；若隐藏两侧后标题失去意义，往往是标题过于空泛，不是构图的问题。

## 2. 倒三角：让重量向下收束

倒三角的上方更宽、下方更窄，容易让人感到重心悬置、空间受压或能量被汇向底部。它适合悬疑、音乐、警示和带有明确结论点的活动；不适合需要强调可靠、舒适或长篇阅读的内容。

### 把压力落在有意义的终点

倒三角最常见的失败是“上面塞满、下面挤小字”。正确的写法要提前声明底部尖点承担什么：一句发布语、一个日期，还是一个行动按钮。它不能既是视觉尖点，又塞进三行说明。

```text
为实验音乐夜制作 3:4 海报，采用倒三角构图。
上半部是宽幅、断裂的黑白文字和抽象声波图形，信息由宽到窄逐级收束；
底部中央只有“10.18 / 20:00”这一项高对比信息，作为尖点终点。
标题可跨越上部两列，但正文保持水平、字号可读。
画面呈现下坠和紧张感；不要把所有文字倾斜，不要让底部尖点挤压日期。
```

可以用内容宽度递减来表达倒三角，背景图形才使用 `clip-path`。MDN 的 [clip-path 参考](https://developer.mozilla.org/en-US/docs/Web/CSS/clip-path)说明该属性会裁剪元素可见区域；因此若把真实文本放入被裁剪层，应特别检查缩放和溢出，避免重要文字被切掉。

```css
.poster__top { inline-size: 100%; margin-inline: auto; }
.poster__middle { inline-size: 66%; margin-inline: auto; }
.poster__point { inline-size: 24%; margin-inline: auto; text-align: center; }
.poster__shape {
  clip-path: polygon(0 0, 100% 0, 50% 100%);
  inset: 0;
  position: absolute;
  z-index: -1;
}
```

## 3. 同心环绕：让中心保持唯一

同心构图用共享中心的圆、圆角框或不规则环层层包围焦点。它可以表达声波、连接、周年、回响或“正在聚焦”的状态。但环线越多，越容易与标题争夺对比，因此需要在需求里规定层数、线宽差异和文字避让区。

```text
制作一张科技社区周年海报，使用同心环绕构图。
中心是周年数字“05”，作为唯一一级焦点；周围设置五层不同透明度的圆环，
环线由外到内逐渐减弱，不与数字重叠。活动名称放在中心下方，
日期、地点和说明沿最外层的下半弧分布，但文字保持水平。
视线从外圈进入中心数字，再读取周围信息。
避免多套不同中心的环，避免用密集细线穿过小字号文本。
```

HTML 中可以使用绝对定位的多个环，并将文字层置于最高层。圆形只是一个可能的外观，重要的是这些元素共享中心：

```css
.poster { position: relative; display: grid; place-items: center; isolation: isolate; }
.ring {
  position: absolute;
  border: 1px solid color-mix(in srgb, currentColor 28%, transparent);
  border-radius: 50%;
}
.ring--1 { inline-size: 88%; aspect-ratio: 1; }
.ring--2 { inline-size: 68%; aspect-ratio: 1; border-width: 2px; }
.ring--3 { inline-size: 44%; aspect-ratio: 1; opacity: .55; }
.poster__center { position: relative; z-index: 1; text-align: center; }
```

`color-mix()` 在较新的浏览器中可用，实际项目应依照目标浏览器范围准备纯色回退；不能因为环线只是装饰，就忽略文本在低对比模式中的可读性。

## 4. 框中框：用边界安排观看顺序

框中框适合摄影、建筑、档案、展览和画册封面。外框先定义安全区，中层窗口裁切主视觉，内层小框或标签锁定标题；框外可以承担编号、注释或日期。它的价值在于明确“哪些内容在被展示，哪些内容在解释展示”。

```text
为摄影展制作竖版海报，采用框中框。
外层细框与画面边缘保持统一安全距离；
中层偏向右上的窗口裁切一张建筑照片，照片占画面约 60%；
内层小框放置展名“看见边界”，编号和开放日期排在外框左下。
三个边界线粗细不同，标题不被边线穿过。
不要把所有框做成同样粗细，也不要把照片窗口缩小到像缩略图。
```

嵌套容器比堆叠阴影更容易控制边界。让中层有轻微偏移，同时让文字落在不被照片细节干扰的区域：

```css
.poster { padding: clamp(18px, 4vw, 48px); border: 1px solid currentColor; }
.poster__window { margin: 8% 0 0 8%; padding: 5%; border: 2px solid currentColor; }
.poster__photo { display: block; inline-size: 100%; aspect-ratio: 4 / 5; object-fit: cover; }
.poster__label { inline-size: fit-content; margin: -2rem 0 0 -1rem; padding: .5rem .75rem; border: 1px solid currentColor; }
```

`object-fit: cover` 会裁切图片，必须同时检查 `object-position` 和关键对象的位置。MDN 的 [object-fit 文档](https://developer.mozilla.org/en-US/docs/Web/CSS/object-fit)给出了不同填充方式的行为；不要只在开发者屏幕上看一眼就假设其他比例也安全。

## 把几何构图交给 AI 前的检查表

```text
[ ] 一级信息只占一个角色：顶点、中心、窗口内焦点或底部尖点。
[ ] 二级信息能支持一级，但不会在骨架外生成第二个强焦点。
[ ] 三级信息有稳定背景和最小字号空间。
[ ] 线、环、框或裁切没有穿过重要文字、脸部、产品标志和交互区域。
[ ] 骨架在缩小预览中仍能读出，而不是依赖复杂纹理。
[ ] HTML 版在窄屏重新计算尺寸，不直接沿用桌面像素坐标。
```

## 常见失败与修复方式

### 把辅助线当成成品

三角、螺旋、同心圆直接覆盖在所有内容上，会让海报像设计练习纸。先尝试删掉线，只保留被线约束的位置；如果阅读顺序仍存在，说明骨架已经完成工作。

### 形状比内容更显眼

环线、框线和尖角的对比若超过标题，观众会先看装饰。降低线的明度、透明度或数量，或者给标题增加更稳定的背景与尺度。

### 裁切只看“满不满”

窗口或三角背景填满了，并不代表裁切正确。对人物检查脸、手、关节和视线方向；对产品检查标识、轮廓和关键结构；对文字检查字首、字尾和行间安全区。

### 用一个骨架解决所有信息

几何构图适合信息关系明确的海报。若需要展示大量课程、多个价格、长介绍和多张图片，应先考虑网格、分栏或页面层级，而不是把所有内容塞进一个三角或圆环。

## 结论与限制

三角、倒三角、同心环和框中框的共同点，是先替内容分配角色：哪里强调，哪里展开，哪里承载细节。提示词一旦写出这些角色，图像模型和前端 Agent 就能围绕同一套空间规则工作。

不过，几何骨架不能自动保证海报有效。真实文案的长度、图片授权、品牌字体、投放尺寸和无障碍需求都会改变最终判断。先用骨架完成层级，再在实际尺寸与真实内容中验证，才比追逐一张“看起来很设计”的首稿可靠。
