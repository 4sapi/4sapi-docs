# 如何用矛盾地图整理多视角研究中的分歧与共识

研究材料最容易被忽略的部分，往往不是共识，而是不同观点为什么互相冲突。有人讨论平均效果，有人讨论最坏情况；有人关心上线速度，有人关心责任和成本。把这些内容压成“各有利弊”，看似客观，实际上没有告诉决策者下一步该查什么。本文介绍一种矛盾地图：先明确主张，再区分事实、因果、价值和范围冲突，最后把分歧转成可验证的问题和一页研究简报。

## 矛盾地图要解决的三个问题

一张有用的地图至少要回答：

1. 两个视角究竟在哪一句主张上冲突？
2. 双方证据是直接研究、案例、类比还是推测？
3. 哪条新信息可能同时改变双方结论？

例如，讨论“企业是否应该使用 AI Agent”时，实践者可能说“限定范围后可用”，怀疑者可能说“尾部失败不可接受”。两者不一定争同一件事：前者谈日常运营，后者谈低概率高损失事件。先拆开对象，才知道需要查平均指标、失败案例，还是责任制度。

## 输入材料要保持完整

矛盾地图不是凭空生成的。把多视角扫描的**主张、证据和不确定性**一起粘贴进去；只粘贴每个角色的结论，模型只能比较语气，不能比较依据。材料不足时，应先补资料或把结论标记为“未核验”。

## Prompt：生成矛盾地图

```text
下面是针对同一话题的 5 种视角分析。
请基于这些材料生成一张矛盾地图，不要新增未出现在材料中的事实。

1. 列出直接冲突的主张，并逐条写出双方原主张。
2. 给每处冲突分类：
   - 事实冲突：对同一事实的描述不同
   - 因果冲突：承认事实，但对原因解释不同
   - 价值冲突：事实相近，但目标或风险偏好不同
   - 范围冲突：对象、时间、行业、样本或成功标准不同
3. 比较双方证据：直接研究、统计数据、案例、访谈、历史类比或推测。
4. 判断哪条证据更关键，并解释理由；不要用表达是否有说服力作为理由。
5. 写出一个可以通过数据、文献或访谈验证的问题。回答它应能缩小最大的分歧。
6. 列出所有视角都同意的内容，并注明证据范围。
7. 列出所有视角都没有触及的盲区，并说明它为什么可能被忽略。
8. 建议一个可能改变结论的第六视角。

请严格按以下格式输出：

## 共同结论
## 主要冲突
| 冲突 | 涉及视角 | 冲突类型 | 双方主张 | 证据差异 |
## 最大分歧与待验证问题
## 全部视角的共同盲区
## 建议补充的第六视角

无法确认的内容标记为“需要外部核验”。不要为了让地图完整而补造证据。
```

## 四类冲突分别怎么处理

### 事实冲突：回到原始来源

如果一方说“失败率很低”，另一方说“失败案例很多”，先核对数据日期、样本量、失败定义和统计口径。不同口径不能直接投票。

### 因果冲突：寻找可区分的预测

双方可能同意结果，却对原因有不同解释。要求每种解释提出一个不同的可观察预测，再用数据判断哪种解释更能解释结果。没有可区分预测的因果说法，只能暂列为假设。

### 价值冲突：明确谁承担风险

CTO 关心交付速度，合规负责人关心数据泄露，财务负责人关心预算上限。它们不一定有一个脱离目标的“唯一正确答案”，需要先写明目标、不可接受风险和决策期限。

### 范围冲突：统一问题边界

把“AI 能不能做客服”改写成“在日均 1 万次、有知识库、允许转人工、响应时间低于 5 秒的场景中，AI 是否能降低单位成本且不降低一次解决率”。问题具体后，证据才有可比性。

## Prompt：把地图综合成研究简报

矛盾地图告诉你“分歧在哪里”，还需要一份简报告诉你“当前能做什么”。把原始视角和地图一起交给 Claude：

```text
请把上面的 5 种视角和矛盾地图综合成一份研究简报。

1. 用一段话总结当前最稳妥的判断，写清适用范围和最大风险。
2. 列出 5 条关键发现，按当前材料的可靠性排序。
3. 每条发现都列出：支持视角、挑战视角、支持证据、反对证据和缺失信息。
4. 找出一条只有把多个视角放在一起才能发现的隐藏连接，并标记为“综合推断”。
5. 针对 [我的角色]，给出一个具体动作、前置条件、负责人和停止条件。
6. 提出一个回答后可能改变整体结论的前沿问题。

请把事实、推断和建议分开。不要把视角数量当成证据数量；多数视角同意也不能自动变成确定事实。资料不足时写“当前资料不足以判断”。
```

## 简报的最小验收表

| 区块 | 必须回答 | 常见问题 |
| --- | --- | --- |
| 结论先行 | 当前判断、边界、最大风险 | 只写“利弊并存” |
| 关键发现 | 证据、反证和缺口 | 只按重要性排序，不看可靠性 |
| 分歧 | 冲突类型和待验证问题 | 把价值偏好当事实争议 |
| 角色动作 | 负责人、前置条件、停止条件 | 只给“建议进一步研究” |
| 前沿问题 | 什么答案会改变决策 | 写成无法验证的口号 |

“可靠性排序”只是当前材料下的复核优先级，不是事实真值。它的作用是告诉你先花时间检查哪一条，而不是替你完成审查。

## 何时地图会误导

如果五个视角都来自同一篇报道，地图可能只是把同一份偏见拆成五种语气；如果输入材料没有时间范围，冲突可能来自旧资料和新资料的混合；如果问题本身没有定义成功标准，价值冲突会被错误地包装成事实结论。因此，输出前要保留来源、日期、样本和适用范围，必要时补充真实数据或访谈。

## 结语

矛盾地图不是让模型替你选边，而是把“专家在哪里分歧、为何分歧、下一步查什么”写清楚。研究材料有冲突并不可怕，真正危险的是把冲突抹平后，带着虚假的共识做决定。
