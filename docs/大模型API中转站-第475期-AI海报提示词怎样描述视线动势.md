# AI 海报提示词怎样描述视线动势

“做得更有动感”是一句难执行的反馈。它没有说明画面是从左下冲向右上，还是从中心向外爆发；也没有说明标题应该顺着动势走，还是保持水平来承接信息。结果往往是所有字都被旋转，所有元素都在飞，真正该读的内容反而消失。

动势的本质是阅读路径：视线从哪个入口进入，沿哪一条轴或曲线经过哪些节点，最后停在何处。本文将对角线、放射、Z 型和 S 型四种路径转成可交给图像模型和 HTML Agent 的任务描述。适合体育、音乐、活动、产品首屏等需要传达速度或连续叙事的场景。

## 先决定路径，再决定特效

开始前不要急着列风格词，先回答：

```text
入口：画面里第一个被看见的对象是什么？
路径：直线、放射、折线还是曲线？方向从哪里到哪里？
节点：路径上需要读到哪两到四项信息？
终点：日期、行动按钮、结论还是另一个视觉对象？
静止区：哪一部分必须保持水平、稳定和可读？
```

动势不等于元素都移动。大多数海报只需要一个强轴线或几个节点有方向感，说明性正文仍应保持水平。这样观众可以先感到速度，再读到内容。

| 路径 | 阅读方式 | 适合 | 主要风险 |
| --- | --- | --- | --- |
| 对角线 | 沿一条强斜轴从角到角 | 体育、促销、行动主题 | 全部文字跟着倾斜 |
| 放射 | 从中心向外扩散，再回到中心 | 庆典、音乐节、宣言 | 出现多个中心，射线干扰小字 |
| Z 型 | 在四个角之间分段交接 | 活动介绍、首屏、课程 | 四个角同样强，读者失去起点 |
| S 型 | 通过反向曲线串联多个节点 | 时尚、自然、舞蹈、饮品 | 曲线只是装饰，节点没有信息 |

## 1. 对角线：让斜轴指向有效内容

对角线打破水平和垂直的安定感，容易建立速度、冲突和方向。设计任务里应明确斜轴的起点、终点、承载对象，以及哪些文字不应该旋转。

```text
制作一张 3:4 竖版跑步活动海报。
用一条从左下穿向右上的强对角轴组织画面；跑者跨在斜轴中段，
主标题“向前，不等风”与斜轴平行但不超过两行；
日期、地点和报名提示位于右下安全区，保持水平排版。
视线从左下的起跑标记进入跑者，沿斜轴到标题，再落到右下执行信息。
避免每一行文字旋转，避免斜轴把视线直接带出画面。
```

HTML 中可让一条背景色带倾斜，再将文字与图片放在独立的内容层。`transform` 会影响元素的视觉呈现，但不应被用来让正文整体难以阅读。MDN 的 [transform 文档](https://developer.mozilla.org/en-US/docs/Web/CSS/transform)可用于核对旋转和缩放效果的实现。

```css
.poster { position: relative; overflow: hidden; }
.poster::before {
  content: "";
  position: absolute;
  inset: 30% -18%;
  background: var(--accent);
  transform: rotate(-26deg) scale(1.35);
  z-index: 0;
}
.poster__title, .poster__meta, .poster__subject { position: relative; z-index: 1; }
.poster__meta { transform: none; }
```

验收时沿斜线用手指或鼠标比划一遍：它是否经过跑者和标题，并停在日期？若它指向空角落，先改轴线或终点位置，而不是添加更多速度线。

## 2. 放射：中心必须只有一个

放射构图把线、色块、人物姿态或文本方向从共同中心向外展开。它尤其适合有高情绪强度的活动，但前提是中心足够明确。中心可以是一个字、一张脸、一个徽章或一个产品，不应同时出现三个“中心”。

```text
3:4 竖版音乐节海报，以主标题“LIVE NOW”为唯一放射中心。
粗细不同的色带从标题周围向边缘扩散，主唱剪影位于中心后方但不遮住字；
阵容和日期分布在边缘较安静的区域，字号小于主标题且不被射线穿过。
阅读顺序是中心标题 -> 周边阵容 -> 底部日期。
不要添加第二个放射源；细密射线只作低对比背景，不干扰小字号。
```

纯 CSS 可用 `repeating-conic-gradient()` 做背景射线。MDN 的 [conic-gradient 文档](https://developer.mozilla.org/en-US/docs/Web/CSS/gradient/conic-gradient)说明，这类渐变围绕中心旋转；使用时应将它放在内容下层，并为中心文字提供足够的对比。

```css
.poster {
  position: relative;
  display: grid;
  place-items: center;
  isolation: isolate;
}
.poster::before {
  content: "";
  position: absolute;
  inset: 0;
  background: repeating-conic-gradient(from -10deg, #ffdf4a 0 8deg, #e45035 8deg 15deg);
  opacity: .32;
  z-index: -1;
}
.poster__center { padding: .3em .5em; background: #111; color: #fff; }
```

缩小海报后，如果最先被看见的是某一条边缘射线而不是中心内容，说明射线对比过强或中心块太小。降低背景不透明度通常比继续增加射线数量更有效。

## 3. Z 型：把顺序信息放在四个锚点

Z 型路径适合内容不多、但阅读顺序明确的页面或海报。最常见的排列是左上标题、右上主视觉、左下说明、右下行动信息。它不是人在所有场景下都会遵循的固定眼动规律，而是一种帮助团队安排少量信息的脚手架。

```text
为线上课程制作竖版信息海报，使用清晰的 Z 型路径。
左上放课程主标题“从零搭建可验收 Agent”；右上放课程封面插图；
左下用三行说明列出适合人群和开课时间；右下放醒目的“查看课程安排”。
用插图朝向和低对比细线建立两次交接，不直接画字母 Z。
四个角中标题最重要，行动信息第二重要，其余内容明显退后。
```

2×2 Grid 可先把四个锚点稳定下来。右下的行动信息可以使用更高的色彩对比，但不应比标题大到抢走入口：

```css
.poster {
  display: grid;
  grid-template-columns: 1fr 1fr;
  grid-template-rows: 1fr 1fr;
  gap: clamp(16px, 3vw, 40px);
  padding: clamp(20px, 5vw, 64px);
}
.poster__title { grid-area: 1 / 1; }
.poster__visual { grid-area: 1 / 2; align-self: start; }
.poster__detail { grid-area: 2 / 1; align-self: end; }
.poster__cta { grid-area: 2 / 2; align-self: end; justify-self: end; }
```

验证时把四块内容替换成只有轮廓的占位块，检查路径是否仍然成立。若一定要靠箭头和许多连线才看得出顺序，说明四个区域的对比、朝向或位置关系不足。

## 4. S 型：每个转弯都要交接信息

S 型曲线通过两个相反方向的弧段连接多个节点，适合优雅、流动、渐进式的叙事。它尤其适合主视觉本身带有曲线的内容，例如舞者姿态、衣料、植物、饮品倾倒轨迹。重点不是画一条漂亮曲线，而是在曲线每次转向时放置有意义的信息节点。

```text
制作一张竖版饮品发布海报，以隐性的 S 型路径组织内容。
顶部左侧是饮品名称，液体倾倒的轨迹穿过中间产品瓶身，
底部右侧放口味和上市日期；三个节点沿同一条柔和曲线依次连接。
正文保持水平，曲线只由液体、光影和产品朝向暗示。
不要使用没有节点的装饰曲线；不要让底部日期落在液体高细节区域。
```

如果产品和文字需要严格依附于曲线，可使用 SVG path；若只是为背景增加柔和引导，则用两个大圆弧或图片中的自然姿态即可。无论使用哪种方式，正文都应保留独立的阅读区。SVG 的 [path 元素文档](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/path)可用于核对路径定义；不建议把小字号文字强行沿路径排版。

```css
.poster { position: relative; min-block-size: 720px; overflow: hidden; }
.poster__node { position: absolute; max-inline-size: 12ch; }
.poster__node--1 { inset: 10% auto auto 12%; }
.poster__node--2 { inset: 42% 14% auto auto; }
.poster__node--3 { inset: auto auto 12% 16%; }
```

窄屏上，这三个节点不必继续绝对定位成同样的 S。若屏幕高度和图片比例不足，改成从上到下的阅读顺序比硬保留曲线更可靠。

## 一份可复制的动势提示词

```text
制作一张【比例】海报，用于【场景】。
主题是【主题】，唯一一级焦点为【标题/对象】。

动势采用【对角线 / 放射 / Z 型 / S 型】。
入口是【位置和对象】；路径从【起点】沿【方向或曲线】经过【节点 1、节点 2】，
最后停在【日期/CTA/结论】。
主视觉位于【位置】并占画面约【比例】；标题位于【位置】；
说明文字和元信息放在【静止区】，保持水平和足够对比。
允许使用【一条斜色带/低对比射线/隐性弧线】暗示路径，
但不要【所有文字旋转/多中心爆发/细线穿过小字/路径带出画面】。

请先输出：各节点的位置、层级和阅读路线；再生成图像或 HTML。
完成后提供缩小预览，检查第一眼焦点、文字安全区和路径终点。
```

## 生成后如何给出可修复的反馈

以下反馈会比“动感不够”更容易得到有效改版：

```text
问题：左下到右上的斜色带穿过了日期，日期在缩小预览中不可读。
保留：跑者位置和主标题。
修改：将日期移到右下纯色安全区，色带在日期前结束；日期保持水平。
验收：390px 宽度截图中，标题、跑者和日期可按顺序识别，日期没有被任何纹理覆盖。
```

反馈应同时说明问题位置、必须保留的内容、允许的修改和验证动作。这样 Agent 不会通过扩大标题或堆叠装饰来“补动感”。

## 限制与结论

动势可以建立速度和叙事，但不适合所有主题。需要长期阅读、数据密集或强调严谨的内容，通常更适合稳定的网格与明确分栏。即使在活动海报中，也应把可读性放在路径效果之前。

一张有动势的海报不需要让每个元素都倾斜或飞散。先指定入口、路径、节点、终点和静止区，再选择少量能支持这条路径的图形关系，AI 才能把“动感”实现为可阅读的视觉结构。
