# 【大模型API中转站】第138期 WorkBuddy零门槛入门 | 妈妈也能用

本文是【大模型API中转站】系列的第138篇。本系列致力于用最低的成本、最清晰的方法，帮你打通多模型API的任督二脉。建议先收藏，随用随查。

前面写过 Claude Code、Codex、OpenCode，也写过 WorkBuddy 的 Skills、自动化和企业治理。

但很多普通用户的真实反馈是：

```text
Claude Code 很强，但我用不上。
Codex 很好，但安装、登录、权限、环境都太折腾。
我只是想写汇报、做 PPT、整理文件、改个小网页。
```

这篇就换一个入口。

不从命令行讲起。

不从 API Key 讲起。

不要求你会写代码。

这篇只讲：

```text
怎么把 WorkBuddy 当成一个普通人能上手的 AI 助手。
```

先说结论：

```text
如果你不打算硬啃开发流程，也不想折腾海外工具，
WorkBuddy 是目前国产通用 Agent 里比较适合新手打开的选择之一。
```

日常办公里那些活：

```text
汇报要写。
PPT 要出。
数据要理。
文档要改。
邮件要发。
小网页要做。
```

WorkBuddy 都能接一大半。

它不一定是最强代码 Agent。

但它把“普通人怎么开始用 Agent”这件事，做得比很多开发者工具友好。

## 1. 先装上：别被环境劝退

官网入口：

```text
workbuddy.cn
```

Mac 和 Windows 都有客户端。

下载对应系统版本，双击安装，一路默认即可。

WorkBuddy 对新手最友好的一点，是登录环节：

```text
微信扫码。
```

不用先去申请 API Key。

不用填一堆 Base URL。

不用配置代理。

不用命令行安装。

流程就是：

```text
下载
-> 安装
-> 打开客户端
-> 微信扫码
-> 授权登录
-> 进入主界面
```

如果你之前被 Claude Code、Codex、Cursor 的各种登录和环境配置劝退过，这一步会明显轻松很多。

这也是它适合“小白第一站”的原因。

## 2. 主界面先别急着发消息

第一次打开 WorkBuddy，不建议马上输入任务。

先花两分钟看布局。

WorkBuddy 主界面可以粗略分成三块：

```text
中间：对话区和场景入口。
左侧：助理、项目、专家、自动化、文件、知识库、灵感。
底部或侧边：工作空间和任务产物。
```

中间的大对话区，就是你和 WorkBuddy 说话的地方。

上方一般能切三类场景：

```text
代码开发
日常办公
设计创意
```

这三个不是装饰。

你切到哪个场景，下方快捷入口就会变化。

切到日常办公，常见入口是：

```text
文档处理
数据分析可视化
深度研究
幻灯片
```

切到代码开发，常见入口是：

```text
日常开发
网站开发
Agent 应用
Skill 开发
```

切到设计创意，常见入口是：

```text
网站设计
App 端
PPT
原型
品牌
```

新手最应该先用这些入口。

不要一开始就自己憋一句大而全的提示词。

系统预置入口会帮你把任务拆得更清楚。

## 3. 三档工作模式：先把这个搞懂

WorkBuddy 的一个关键开关，是工作模式。

常见有三档：

```text
Craft
Ask
Plan
```

把它们理解成三种性格就行。

### Craft：直接开干

Craft 是完整 Agent 模式。

你发任务，它会自己规划、读文件、写文件、生成产物。

适合：

```text
整理文档。
生成 PPT。
分析数据。
做网页。
批量处理文件。
```

但新手要注意：

```text
Craft 一启动，就可能开始消耗积分。
```

如果你只是想问一句：

```text
这个功能在哪里？
这段话什么意思？
这个按钮该点吗？
```

不要用 Craft。

### Ask：只问答

Ask 就是普通聊天。

问一句答一句。

适合：

```text
问概念。
问用法。
问软件设置。
让它解释一段话。
```

如果你只是想先了解一下，不想让它动文件、跑任务、扣太多积分，切 Ask。

### Plan：先出方案

Plan 是新手最稳的模式。

你给需求，它先给计划。

你确认后，再让它执行。

适合：

```text
第一次跑某个任务。
不确定会不会改文件。
担心它乱动。
任务比较大，需要先看步骤。
```

我建议新手第一周默认用：

```text
Plan -> 确认 -> Craft 执行
```

不要一上来全程 Craft。

## 4. 模型怎么选：先别追最贵

WorkBuddy 里能选多种国产模型。

常见会看到：

```text
腾讯混元
DeepSeek
GLM
Kimi
其他兼容模型
```

不同模型消耗积分不同。

新手不用一开始就追“最强”。

更合理的选法是：

```text
普通文档、总结、改写：性价比模型。
长文档、复杂分析：能力更强的模型。
代码和 Agent 任务：选更擅长工具调用和编码的模型。
设计创意：看模型是否支持对应视觉或设计能力。
```

如果你没有偏好，可以从综合能力较稳、成本友好的模型开始。

比如附件里提到的 DeepSeek V4 Pro，就是一种“先跑起来”的思路。

但这里不要迷信某个名字。

模型会变。

真正要养成的是：

```text
低风险任务用便宜模型。
高价值任务再换强模型。
```

如果你已经有自己的 API Key，也可以在：

```text
设置 -> 模型 -> 添加模型
```

接入兼容 OpenAI 协议的接口。

团队场景下，也可以通过 4SAPI 做统一模型入口，把不同模型、Key、预算和日志收起来。

## 5. 权限：默认权限更适合新手

WorkBuddy 常见有两档权限：

```text
默认权限
完全访问
```

默认权限的特点是：

```text
遇到风险动作会停下来问你。
```

完全访问的特点是：

```text
它能一路放行，少弹确认。
```

老手为了省事，可能会开完全访问。

但新手我建议先用默认权限。

原因很简单：

```text
你还不知道它会动哪些文件。
你还不知道任务会生成什么。
你还不知道哪些动作算高风险。
```

第一周先默认权限。

等你熟悉它的行为，再决定是否给更高权限。

有一句话要记住：

```text
Agent 的权限越大，越要先建立工作空间和备份习惯。
```

## 6. 工作空间：把它当项目文件夹

WorkBuddy 里的工作空间，可以理解成：

```text
项目文件夹。
```

每次开始任务前，最好先选一个工作空间。

例如：

```text
工作汇报/
PPT素材/
客户资料整理/
网页小项目/
Skill教程资料/
```

它会基于这个目录读文件、写产物、保存任务结果。

不选也能跑。

但不选的后果是：

```text
文件容易散。
产物不好找。
多个任务混在一起。
后面归档麻烦。
```

所以建议你一开始就按任务建空间。

比如：

```text
2026-07-WorkBuddy教程/
2026-07-部门月报/
2026-07-世界杯网页/
```

前期多花 30 秒，后面少找 30 分钟。

## 7. 上传文件：本地、腾讯文档、知识库都能进来

对话框旁边通常有一个加号。

点开后，可以上传或连接：

```text
本地文件
腾讯文档
知识库
其他支持的资料入口
```

附件里提到 WorkBuddy 和 ima 知识库有联动。

如果你本来就是 ima 用户，这条线会很顺：

```text
ima 里存资料。
WorkBuddy 里调资料。
任务完成后再沉淀成文档。
```

如果你不是 ima 用户，也没关系。

先从本地文件开始。

最小任务是：

```text
上传一个 Word / PDF / Markdown。
让 WorkBuddy 总结。
让它列行动项。
让它生成一份汇报提纲。
```

跑通这个，就已经能处理很多办公任务了。

## 8. 左侧功能区：先记住四个

左侧功能很多。

新手先记四个就够：

```text
助理
项目
专家
文件
```

助理：

```text
日常对话和远程入口。
```

项目：

```text
按任务或项目管理产物。
```

专家：

```text
找已经配置好的垂直 Agent。
```

文件：

```text
查看任务生成的文档、网页、图片、表格等产物。
```

其他功能，比如自动化、知识库文档、灵感，等你跑熟后再碰。

第一天目标不是把所有按钮都学完。

第一天目标是：

```text
让它帮你完成一个真实任务。
```

## 9. 第一次任务怎么跑

给一个最稳的新手任务。

准备一个工作空间：

```text
我的第一次 WorkBuddy 任务/
```

上传一份你真实要处理的文件。

比如：

```text
会议纪要
产品资料
老板发来的要求
一份旧 PPT
一堆 Markdown 素材
```

切到：

```text
日常办公 -> 文档处理
```

模式选：

```text
Plan
```

提示词可以写：

```text
请先阅读我上传的资料。
不要直接生成最终稿。
先帮我列出：
1. 这份资料主要讲什么。
2. 可以整理成哪几类输出。
3. 你建议先做哪一个。
4. 需要我补充什么信息。
```

看完计划后，再说：

```text
按你的建议，先生成一份 800 字汇报稿。
要求：
1. 先给标题。
2. 再给三段正文。
3. 最后列 5 条行动项。
4. 输出成 Markdown 文件，保存在当前工作空间。
```

这样跑，风险很低。

你能看到它怎么计划、怎么生成、产物放在哪里。

## 10. 新手最容易踩的坑

第一个坑：一直用 Craft 问闲聊。

只是问问题就切 Ask。

第二个坑：不建工作空间。

结果文件散落，后面找不到。

第三个坑：一上来开完全访问。

先默认权限，熟悉后再放权。

第四个坑：不看计划直接让它跑大任务。

大任务先用 Plan。

第五个坑：追最贵模型。

普通任务先用性价比模型，高价值任务再升级。

第六个坑：让它一次处理太多文件。

第一次只给 1-3 个文件。

第七个坑：产物不验收。

AI 生成的东西要检查事实、格式和是否符合你的真实需求。

## 11. 4SAPI 在这里的位置

个人用户用 WorkBuddy，直接用内置模型就能开始。

但如果你是团队，就会关心：

```text
不同成员用哪个模型？
积分和 API 成本怎么分摊？
哪些任务用了强模型？
哪些任务能用便宜模型？
日志能不能审计？
```

这时可以把 4SAPI 当成企业级 API 网关：

```text
WorkBuddy / 其他 Agent
-> 4SAPI
-> 多个模型
```

它的价值是：

```text
统一 Key。
统一预算。
统一日志。
统一模型路由。
统一权限边界。
```

不是每个新手都需要一上来配置 4SAPI。

但团队要规模化使用 Agent，迟早需要类似治理层。

## 12. 总结

WorkBuddy 适合谁？

```text
想用 Agent，但不想折腾海外账号的人。
想处理办公任务，但不会写代码的人。
想做简单网页、小工具、PPT、文档整理的人。
想先体验 Agent，再决定要不要学 Claude Code / Codex 的人。
```

第一天不要贪。

只做四件事：

```text
装好。
登录。
建工作空间。
跑一个低风险任务。
```

跑通以后，你就会明白：

```text
Agent 不一定非要从命令行开始。
普通人的 AI 工作流，也可以从一个微信扫码登录的客户端开始。
```
