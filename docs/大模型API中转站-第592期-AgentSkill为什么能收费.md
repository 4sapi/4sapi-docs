# Agent Skill 为什么能收费：从模板生意看审美付费的定价结构

Agent Skill 刚火的时候，出现了一大批"Skill 合集站"：抓几千个开源 Skill 放到网站上，做导航、做分类、做搜索。看起来内容很丰富，但绝大部分不赚钱。

理由很简单。通用规则脚本和提示词，GitHub 上可以免费复制，或者让 AI 自己写，几十秒就有。没有人会为"信息搬运"付钱。

那同样是 Skill，什么样的能收费？本文的产品定价与收入取自公开收入平台 TrustMRR，检索 2026-10-29。

## 这其实是一门老生意

能收费的 Skill，本质上是在卖模板。它和卖 PPT 模板、网页模板、UI 组件是同一门生意。

逻辑链条是这样的：

1. 程序员和 Vibe Coder 的短板很少是写逻辑，而是审美；
2. AI 默认生成的网页、幻灯片、视频有一股"塑料味"；
3. 谁能把审美调好、做成可以直接用的东西，谁就能收钱；
4. 过去这东西叫"模板"，现在换了个载体，叫"Skill"。

这个判断的说服力在于，它不需要发明新需求。"为审美付费"在 UI 组件、PPT 模板、网站主题市场里已经被验证了很多年。新的只是交付方式：从"下载后自己改"，变成"装进 Agent，让它按这个风格做"。

## 用定价拆这门生意

光说"能收费"不够，要看具体怎么收。把几个可查的产品放在一起：

| 产品 | 卖什么 | 定价结构 | 近 30 天收入 | MRR |
| --- | --- | --- | --- | --- |
| Skillry | 网页、幻灯片、图片、视频的风格化 Skill | 免费 Skill + 高级版 $9.99/月或 $79/年 + 终身版 $169 | $12,808 | $4,111 |
| TypeUI | 给 AI 编程工具的 UI 设计风格与组件 | $30/月，7 天试用 | $3,319 | $3,409 |
| ShipFast | Next.js 代码样板 | 买断 $199 / $249 / $299 | $1,694 | 无订阅 |
| Low Content AI | 亚马逊 KDP 低内容图书生成 | 年付 €390 / €490 / €990 | $15,114 | $14,388 |

来源：[TrustMRR · Skillry](https://trustmrr.com/startup/skillry)、[TypeUI](https://trustmrr.com/startup/typeui)、[ShipFast](https://trustmrr.com/startup/shipfast)、[Low Content AI](https://trustmrr.com/startup/low-content-ai)，定价以页面登记为准。

四个产品落在四种定价结构上，正好覆盖了这门生意的主要选项。

## 四种定价结构各自的账

**免费 + 低价订阅 + 终身版（Skillry）**

免费 Skill 负责引流和建立信任，$9.99 的门槛低到可以冲动消费，终身版吃下那批"愿意一次性支持早期项目"的用户。

代价也明显：30 天收入是 MRR 的 3 倍多，说明一次性收入占比很高。终身用户以后不会再付钱，这部分收入不可持续。这是早期冷启动的常见打法，长期要看月付和年付能否接上。

**单一中价订阅（TypeUI）**

只有一个 $30/月的档位，加 7 天试用。结构简单，收入几乎全是经常性的（30 天收入与 MRR 基本相等）。缺点是门槛比 $9.99 高三倍，冲动消费的人少。

**买断（ShipFast）**

一次付清，没有续费。早期能快速回款（累计 $127 万），但没有订阅就没有基本盘。新用户一放缓，收入就会掉下来——现在近 30 天只有 $1,694。

**高价年付 + 垂直人群（Low Content AI）**

年付 €390 起，客群极窄（亚马逊 KDP 卖家），但这群人用它直接赚钱，愿意付高价。几乎不依赖泛流量（Ahrefs 域名评分只有 4/100），却做到了每月 $1.5 万。

## 从这四种结构能读出什么

| 观察 | 依据 | 对做 Skill 的启发 |
| --- | --- | --- |
| 买断制在后期很难看 | ShipFast 累计高、近期低 | 不要只做一次性售卖 |
| 订阅收入更稳 | TypeUI、Low Content AI 的 30 天收入 ≈ MRR | 订阅是基本盘 |
| 终身版能快速回款，但有代价 | Skillry 的收入与 MRR 之比 | 可以做，但要限量或限时 |
| 用户能用它赚钱时，价格可以很高 | Low Content AI 的年付 €390 起 | 找"用了能直接产生收入"的场景 |

最后一条对 Skill 生意特别有意义。给开发者调审美，开发者用它做出更好看的产品，再卖给客户——这条链路里，Skill 是生产工具，不是消费品。生产工具的定价空间比消费品大得多。

## 免费 Skill 合集站为什么不赚钱

反过来看就清楚了：

| 合集站的特征 | 为什么收不到钱 |
| --- | --- |
| 内容来自开源仓库 | 用户能免费拿到原件 |
| 通用提示词和规则 | AI 自己就能写 |
| 数量多但没有风格 | 没有"选它而不选别人"的理由 |
| 没有示例产出 | 用户不知道装了能得到什么 |

最后一条最关键。从平台登记的价值主张看，Skillry 强调的是"安装前先预览真实产出"。**审美没法用文字描述，只能用成品证明**。没有示例的 Skill 站，等于让用户为一段文字说明付费。

## 复制这门生意的三个前提

想做类似的东西，下面三条缺一条都很难成：

**一是你自己真的有审美。** 这门生意卖的是品味，品味不能外包给 AI。如果你做出来的东西本身就带塑料味，Skill 化只会把塑料味复制得更快。

**二是你能持续出新。** 风格会过时，平台会更新。平台登记显示 Skillry 是 1 人团队，持续出新的压力全在一个人身上。订阅用户买的是"持续有新东西"，不是"一次性给一堆"。

**三是你有分发渠道。** 冷启动时，一个已经有关注者的社交账号、一个现成的社区，作用很难量化但肯定不小。没有这个基础的人照做同样的产品，第一个月的数字通常不会一样。

## 不适合做的情况

- 你的 Skill 主要是工作流编排、文件处理这类功能性逻辑：开源替代太多，很难收费；
- 你的目标用户是不付费的人群：学生、纯爱好者，转化率会很低；
- 你只能做一个品类：单一风格的 Skill 很快会被用腻，订阅撑不住。

## 定价怎么试，而不是怎么猜

定价不需要一次定对，但需要有办法知道定错了。几种低成本的试法：

| 试法 | 怎么做 | 看什么 |
| --- | --- | --- |
| 只开放候补名单 | 页面写价格，按钮只收邮箱 | 看到价格后还留邮箱的比例 |
| 两档价格并列 | 月付和年付同时展示 | 年付占比，越高说明用户越确定会长期用 |
| 限量终身版 | 只开放前 N 个名额 | 卖完的速度，衡量早期信任 |
| 免费 Skill 转化 | 免费版安装后追踪升级 | 免费到付费的比例 |

第三种值得多说一句。终身版能快速回款，但每卖出一份，就少一个未来的订阅用户。限量、限时、明确写出"名额用完即止"，是把这种代价控制在可接受范围内的常见做法。

## 一个 Skill 产品的最小定价页

如果今天就要上线，定价页只需要回答五件事：

| 要素 | 写什么 | 为什么 |
| --- | --- | --- |
| 示例产出 | 每个 Skill 一张真实成品图或一个可打开的页面 | 审美只能用成品证明 |
| 支持的 Agent | 明确列出 Claude Code、Codex、Cursor 等 | 用户先判断能不能用 |
| 免费与付费的分界 | 哪些免费，付费多了什么 | 避免用户停在免费版 |
| 更新承诺 | 多久出一次新的 | 订阅买的是持续性 |
| 退款与取消 | 怎么取消、能不能退 | 降低首次付费的顾虑 |

第四条最容易被忽略。没有更新承诺的订阅，用户会理性地选择买一个月、下载完、取消。

## 常见问题

**Q：$9.99 是不是定得太低了？**
要看目标。低价适合冷启动和冲量，代价是每个用户的价值低，需要更多用户才能达到同样收入。TypeUI 定 $30，订阅数只有 Skillry 的三分之一多，MRR 却相差不大。两种都能成立，取决于你更容易获得流量，还是更容易说服高价用户。

**Q：免费 Skill 会不会把付费用户吃掉？**
会，如果免费版太好。免费的部分应该解决一个完整但小的问题，让用户看到"风格是什么样的"，把"更多场景、持续更新、完整模板"留给付费版。

**Q：开源 Skill 被人抄了怎么办？**
文字规则一定会被抄。护城河不在规则本身，而在持续出新的速度、示例的质量和分发渠道。

## 限制与结论

本文的定价与收入来自公开收入平台的登记信息，可能与产品官网当前定价有出入；四个产品的样本太小，不能代表整个市场。

可以确定的是：带审美的 Agent Skill 是"模板生意"在新载体上的延续，这个判断有长期的历史依据。定价上，订阅是基本盘，终身版适合冷启动但不可持续，买断制在后期会很难看，能让用户直接赚钱的场景可以定更高的价。

最需要记住的是三个前提：你得真有审美，得能持续出新，还得有人知道你。工具让做 Skill 变容易了，这三件事没有变容易。
