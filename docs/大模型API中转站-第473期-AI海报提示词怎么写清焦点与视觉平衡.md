# AI 海报提示词怎么写清焦点与视觉平衡

让 AI 做海报时，写上“极简、电影感、瑞士风格”并不能决定标题该放在哪里。模型可能给出一张颜色和质感都接近预期的图，却让人物、标题、装饰和日期同时争夺注意力。问题不一定在于风格描述不够多，而在于需求没有说明：第一眼应该看什么，其他信息如何退后，以及空白区域准备给谁用。

本文只解决“单个主视觉如何建立焦点和稳定感”这个问题。内容适用于图像生成提示词，也适用于让 Agent 输出 HTML/CSS 海报。读完后，你可以把“高级一点”换成位置、比例、阅读路径和验收条件。

## 先把焦点写成可观察的关系

一张信息不多的海报通常至少有三层：主标题、主视觉、辅助信息。这里的主视觉可以是人物、产品、一个符号，或一个大字号词组。它们不需要平均分配面积；相反，应当先指定唯一的一级信息。

提交任务前，先填完这五项：

```text
画布：3:4 竖版，还是 16:9 横版？
一级焦点：标题、人物或产品，三者中谁先被看到？
位置与面积：它位于哪里，约占画面多大范围？
阅读路线：视线从哪里进入，经过什么，再停在哪里？
留白：哪一块必须保持安静，不能放入装饰和小字？
```

“把产品放中间”仍不够具体。相比之下，“产品视觉中心在纵轴上，宽度约占画面三分之一，标题在上方，日期沿底部居中，左右保留等量空白”能够同时限定层级、位置和间距。

对网页海报，二维区域适合用 CSS Grid 表达。MDN 的 [CSS Grid Layout 指南](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout)说明，Grid 可以用显式的行列和对齐关系安排元素；这比用大量绝对定位把所有文字钉死在像素坐标上更容易维护不同尺寸的画布。

## 五种先决定焦点的构图

以下五种不是互相排斥的“画风”，而是处理主次关系的骨架。一次任务最好选一种做主构图；需要补充关系时，再增加一个辅助约束。

| 构图 | 焦点如何建立 | 适合的内容 | 常见误用 |
| --- | --- | --- | --- |
| 中轴对称 | 主元素落在中线，左右重量接近 | 单一产品、典礼、展览通知 | 把每一行小字都镜像，画面变得僵硬 |
| 非对称平衡 | 大形体偏向一侧，另一侧用小而强的文字或色块配重 | 文化活动、时尚、科技主题 | 只把主体移到左边，另一侧没有回应 |
| 三分法 | 焦点接近分割线或交点，留出朝向一侧的空间 | 人物、产品、摄影主导封面 | 为卡住交点而裁掉主体或挤压标题 |
| 比例收束 | 大区域引导到逐渐缩小的内容簇 | 叙事、自然、概念主题 | 把辅助螺旋线直接画进成品 |
| 大留白单点 | 用主动空白隔离一个小而清晰的对象 | 香氛、艺术展、安静的产品传播 | 只把所有元素缩小，焦点本身没有对比 |

### 1. 中轴对称：把稳定感写成中线和层级

中轴对称不要求画面中的所有东西完全相同。更重要的是，标题、主视觉、日期这几组主要内容共享一条垂直轴，形成从上到下的阅读顺序。小范围的材质变化或微小偏移可以保留，但不应抢走中心。

```text
制作一张 3:4 竖版展览海报。
采用中轴对称：主标题“材料的回声”位于顶部中央；
一件半透明玻璃装置位于垂直中轴，视觉高度占画面约 42%；
日期、地点、署名按重要性沿底部中线排列。
视线从标题沿中轴进入装置，最后到日期。
左右留白接近等量，只有一个主焦点；避免镜像复制小装饰和随机散落文字。
```

若要让 Agent 生成网页版本，可用三行单列 Grid。中线只作为调试辅助，不必显示给观众：

```css
.poster {
  aspect-ratio: 3 / 4;
  display: grid;
  grid-template-rows: auto 1fr auto;
  place-items: center;
  padding: clamp(24px, 6vw, 72px);
}

.poster > * { text-align: center; }
.poster__image { inline-size: min(62%, 440px); }
```

检查时，把画面缩小到手机信息流大小。若标题、主视觉和元信息仍能按上、中、下三段识别，对称关系才算真正生效；若观众首先看到角落装饰，应先删除或弱化装饰，而不是继续给中心加效果。

### 2. 非对称平衡：不是偏置，而是配重

非对称构图的稳定来自视觉重量交换。一个占画面大面积的低对比人物，可以由另一侧较小、但颜色更饱和或字重更高的标题回应。距离也会影响重量：越靠边的对象越容易让人感到它在拉扯画面。

```text
3:4 竖版文化活动海报。使用非对称平衡。
一张颗粒感人像偏向右侧，占画面宽度约 60%，允许右边缘有意裁切；
左侧保留窄而完整的文字区，主标题“夜间阅读”使用高对比大字，
日期和地点沿同一左对齐线排成紧凑信息组。
视线从人像进入，再横向转向标题和日期；左右留白不等量但重量稳定。
不要在两侧放置同样大的图或同样醒目的标题。
```

HTML 海报可以先建立隐形网格，再让主视觉和文字分别占用不同区域：

```css
.poster {
  display: grid;
  grid-template-columns: repeat(5, 1fr);
  grid-template-rows: repeat(6, 1fr);
  overflow: hidden;
}
.poster__copy { grid-column: 1 / 3; grid-row: 2 / 6; align-self: center; }
.poster__image { grid-column: 3 / 6; grid-row: 1 / 7; align-self: stretch; }
```

验收不要只问“看起来偏不偏”。遮住右侧主视觉后，左侧文字是否仍足够明确；遮住左侧文字后，右侧图像是否过重到像被裁坏的截图？这两个对照有助于发现失衡来自哪一侧。

### 3. 三分法：给主体朝向和标题预留空间

三分法可以把横向和纵向都粗略分为三段，将视觉中心放在交点附近。它不是硬性规则，更不要求主体的每一部分都压在交点上。它的实用价值在于先规划主体附近的空区：人物向左看，左边最好有标题或呼吸空间；产品朝右延伸，右边就不宜被密集文字堵住。

```text
横版活动封面，比例 16:9，使用三分法。
演讲者位于右侧三分之一附近，面向左侧；左侧三分线附近排主标题“把模型做成工作流”。
标题下只保留一行副标题和日期，画面中央留出从人物视线通向标题的空区。
人物不可遮住标题，不要为了贴合交点裁掉脸部、手势或麦克风。
```

调试阶段可临时给 Grid 加上三等分背景，确认后再关掉。CSS 的 [渐变背景](https://developer.mozilla.org/en-US/docs/Web/CSS/gradient/repeating-linear-gradient)可以作为纯调试标尺；它不应成为最后的装饰。

```css
.poster {
  display: grid;
  grid-template: repeat(3, 1fr) / repeat(3, 1fr);
}
.poster__title { grid-column: 1 / 2; grid-row: 2 / 3; align-self: center; }
.poster__subject { grid-column: 2 / 4; grid-row: 1 / 3; }
```

### 4. 比例收束：先写“从宽到紧”的路径

一些概念海报需要让视线从较宽的场域逐步进入小的关键对象。可以把它理解为连续缩小的区域：背景或大图承担入口，中尺度文字承担转换，最后由一个短标题、标志或按钮收束。有人会用黄金螺旋来画比例草图，但成品是否有效取决于阅读顺序和文字可读性，而不是是否画出一条数学曲线。

```text
为一场自然影像放映制作竖版海报。
主视觉是一片从左上延伸到中央的雾林；信息按由大到小的节奏向右下收束：
片名在中部，放映时间和售票提示形成右下角的小内容簇。
阅读路径从宽阔的雾林进入片名，最后停在右下角的放映信息。
不要显示螺旋辅助线；小字必须有纯净背景，不能压在高细节照片上。
```

这类构图的验证方式是给内容逐层加临时边框，观察边框大小是否递减、焦点是否落在最后一级。若最终信息需要来回寻找，说明“收束”只停留在装饰上。

### 5. 大留白单点：让空白也承担任务

留白不是剩下的地方。它可以隔开不应互相竞争的元素，让一个很小的对象依然被看见。关键是焦点要同时具备语义和对比：一支小瓶子需要明确的轮廓、材质或色彩；一个词需要足够的字重和邻近的空区。

```text
3:4 竖版产品海报，背景为偏暖的纯色纸张质感。
保留约三分之二的主动留白；一只深色小瓶位于画面偏下、偏右的位置，
宽度不超过画面 22%。产品名紧邻瓶身左侧，日期和说明不超过两行。
焦点由深浅对比和空白隔离建立，画面安静但不空洞。
禁止额外图标、粒子、花纹和第二个产品。
```

网页实现时，把内容簇和容器尺寸分开管理：

```css
.poster { position: relative; min-block-size: 720px; padding: 48px; }
.poster__cluster {
  position: absolute;
  inline-size: min(28%, 260px);
  inset-inline-start: 56%;
  inset-block-start: 62%;
}
```

绝对定位适合这一小簇的有意偏置，但不要把整张页面都交给它。移动端应重新定义簇的位置或改为 Grid，而不是让桌面坐标原样缩小。

## 一份通用的焦点任务书

当你还没有决定具体构图时，先把以下模板交给模型或设计 Agent。方括号内的内容必须由项目提供，不能让模型擅自编造活动日期、产品特性或人物信息。

```text
目标：制作一张【比例】海报，用于【投放场景】。
受众在【距离/设备】上首先应读到【一级信息】。

主构图：使用【中轴对称 / 非对称平衡 / 三分法 / 比例收束 / 大留白单点】。
主视觉：【对象】位于【位置】，约占画面【比例】；不得遮挡【关键部位】。
阅读路径：从【入口】经过【中间节点】到【终点】。
信息层级：一级【标题】；二级【副标题】；三级【日期、地点或说明】。
空间规则：【哪一块】保持留白；所有文字与边缘至少保留【安全距离】。
视觉限制：使用【色彩/材质】；避免【多焦点、随机文字、误裁切、无关装饰】。

交付：先给出构图说明和内容区域图，再生成图像或 HTML。
验收：在原尺寸和缩小预览中，能在数秒内识别一级信息；文字无重叠、无被裁切、无贴边。
```

## 从第一版中定位焦点问题

第一版不理想时，不要只追加“更有高级感”。先根据失败现象修改一个变量：

| 现象 | 可能原因 | 优先修改 |
| --- | --- | --- |
| 不知道先看标题还是图片 | 两者面积、明度或颜色对比过于接近 | 明确其中一个为一级，降低另一个的对比 |
| 标题没有空间 | 主视觉没有预留文字区 | 改用三分法或非对称平衡，先固定文字区域 |
| 画面看起来偏一边 | 偏置没有获得文字、色块或留白回应 | 增加对侧配重，或缩小靠边主体 |
| 极简版显得空 | 留白中没有具有识别度的焦点 | 增强单点的轮廓、材质或语义 |
| 缩小后全是小字 | 信息层级没有尺度差 | 删除非必要信息，拉开标题与辅助文字的字号 |

## 限制与结论

构图约束能够让 AI 和前端实现者更清楚地理解焦点与阅读顺序，但不能替代真实内容。产品照片是否可用、文字是否准确、人物肖像是否有授权，都需要在生成前由项目方确认。

对焦点与平衡而言，最有用的提示词不是又增加一个风格标签，而是说清一件事：谁是主角，它在哪里，观众从哪里开始看，以及其他内容怎样退让。把这些关系写出来，图像生成和 HTML 实现才有可检查的共同目标。
