# 【大模型API中转站】第143期 图生视频实战 | 用首帧锁住主体和品牌

本文是【大模型API中转站】系列的第143篇。本系列致力于用最低的成本、最清晰的方法，帮你打通多模型API的任督二脉。建议先收藏，随用随查。

上一篇讲了文生视频。

文生视频适合从无到有。

你只有一句话，也能先生成一个视觉方向。

但如果你要做商业素材，尤其是：

```text
产品广告。
人物主视觉。
课程封面动效。
电商商品短视频。
品牌海报动态化。
App 界面展示。
```

那更建议用图生视频。

图生视频就是 Image to Video。

你先给模型一张图。

模型基于这张图生成动态视频。

它的核心优势只有一句话：

```text
用首帧锁住主体。
```

文生视频像让模型自由画。

图生视频像给模型一张定稿，让它动起来。

这就是差别。

先说结论：

```text
只要视频里有明确产品、人物、品牌风格或固定构图，优先用图生视频。
```

它比文生视频更适合商业场景。

但它也不是万能。

如果首帧图本身不干净，Prompt 又要求太多动作，生成结果一样会崩。

所以图生视频的关键不是“上传图片然后点生成”。

而是：

```text
先把首帧图做对。
再让模型做很小、很稳、很可剪辑的运动。
```

## 1. 图生视频适合什么

图生视频适合这些场景：

```text
产品图动起来。
海报动起来。
人物主视觉动起来。
课程封面动起来。
App 界面 mockup 动起来。
电商主图做成 5 秒短视频。
PPT 封面做成开场视频。
品牌 KV 做成社媒素材。
```

这些场景有一个共同点：

```text
主体已经确定。
```

你不希望模型重新设计主体。

你只希望它做：

```text
轻微推进。
轻微横移。
背景光效。
产品高光。
头发或衣物轻动。
水雾、烟雾、粒子。
屏幕里的抽象动效。
```

图生视频不适合什么？

```text
复杂剧情。
大幅度人物动作。
精确口播。
复杂手部操作。
从一张图变成完全不同场景。
让一个静态产品完成复杂机械演示。
```

你可以让图动起来。

但不要指望它理解完整动作戏。

## 2. 图生视频和文生视频怎么选

最简单的判断：

| 问题 | 选文生视频 | 选图生视频 |
| --- | --- | --- |
| 有没有现成图片 | 没有 | 有 |
| 主体是否必须一致 | 不太重要 | 很重要 |
| 产品是否真实存在 | 不一定 | 是 |
| Logo 是否要保持 | 不建议 | 可以尝试，但仍要验货 |
| 是否做品牌素材 | 概念阶段可以 | 更推荐 |
| 是否追求自由创意 | 更适合 | 受首帧约束 |
| 是否追求可控 | 较弱 | 更强 |

一句话：

```text
没有素材，用文生视频找方向。
有素材，用图生视频做可用素材。
```

如果你要做企业客户、产品宣传、电商素材，图生视频通常更靠谱。

## 3. 首帧图决定了上限

很多人图生视频失败，不是视频模型问题。

是首帧图不适合。

常见问题：

```text
图片太糊。
主体太小。
背景太乱。
文字太多。
Logo 太细。
光线不统一。
人物手部太复杂。
产品边缘被遮挡。
构图已经不适合视频裁切。
```

模型只能在你给的图上做延展。

首帧图越干净，视频越稳。

我建议首帧图满足这几个条件：

```text
主体清楚，占画面 30%-60%。
背景干净，不要塞太多信息。
光线方向明确。
不要有大段文字。
Logo 可以有，但不要太小太密。
人物尽量避开复杂手势。
产品边缘完整，不要被遮挡。
画幅直接按发布平台准备。
```

比如你要发小红书。

不要上传横图再指望模型帮你变竖屏。

先准备 9:16 首帧。

要发官网横幅，就准备 16:9。

画幅不要交给模型临场发挥。

## 4. 首帧图怎么准备

图生视频的首帧来源可以有四类：

```text
真实拍摄图。
设计海报。
AI 生成图。
产品渲染图。
```

不同来源有不同注意点。

### 真实拍摄图

适合电商、产品、人物、空间。

注意：

```text
尽量用高分辨率原图。
不要用压缩过的聊天截图。
主体边缘要清楚。
背景不要太乱。
光线不要太花。
```

真实拍摄图最自然。

但如果画面里有文字、手部、反光和复杂纹理，模型也容易出错。

### 设计海报

适合课程封面、活动海报、品牌 KV。

注意：

```text
文字最好后期加，不要让模型动文字。
Logo 尽量单独保留静态版本。
背景层和主体层最好能分开。
不要把所有信息都压在一张图里。
```

如果海报里已经有很多字，图生视频很容易把字弄变形。

更稳做法是：

```text
先生成无文字动态背景。
再在剪辑软件里加标题和 Logo。
```

### AI 生成图

适合概念片、角色图、视觉风格图。

注意：

```text
先把图修干净。
不要带 AI 生成里的奇怪文字。
人物手部尽量别出镜。
产品形状要统一。
```

AI 图本身如果有小瑕疵，视频会把瑕疵放大。

### 产品渲染图

适合硬件、包装、美妆、家居、电子产品。

注意：

```text
产品边缘要完整。
反光不要太复杂。
标签不要太密。
不要让产品和背景颜色太接近。
```

产品渲染图做图生视频很舒服。

因为主体干净。

但仍然要防止标签变形。

## 5. 图生视频 Prompt 公式

图生视频 Prompt 和文生视频不一样。

文生视频要描述“生成什么”。

图生视频更重要的是描述：

```text
保持什么不变。
让什么轻微动起来。
```

我推荐这个公式：

```text
保持主体 + 运动方式 + 运镜 + 背景动态 + 光线变化 + 风格 + 禁止改变项
```

展开：

```text
保持主体：产品形状、人物脸、服装、构图、Logo 不变。
运动方式：轻微转动、高光流动、风吹、粒子、屏幕动效。
运镜：缓慢推进、轻微横移、固定镜头、微距推近。
背景动态：雾气、光斑、水波、窗帘、城市灯光。
光线变化：柔和高光、晨光、霓虹反射、阴影流动。
风格：真实拍摄、广告片、电影感、极简、高级电商。
禁止改变项：不要改 Logo，不要改文字，不要新增物体，不要人物手部。
```

坏 Prompt：

```text
让这张产品图变成高级广告。
```

好 Prompt：

```text
保持图片中的护肤精华瓶外形、标签和位置不变，
只让背景出现轻微水雾流动和柔和高光变化，
镜头从正面非常缓慢地推进，
自然晨光，干净高级的美妆广告风格，
5 秒，9:16，
不要改变瓶身文字和 Logo，不要新增手部，不要新增人物，不要改变产品形状。
```

图生视频的核心是“少动”。

越想大改，越容易崩。

## 6. 四档运动强度

图生视频的运动不要一上来就拉满。

我建议按四档来设计。

| 档位 | 运动类型 | 适合场景 | 风险 |
| --- | --- | --- | --- |
| 1档 | 背景微动、高光流动 | 产品图、海报、封面 | 最稳 |
| 2档 | 缓慢推进、轻微横移 | 广告素材、课程开场 | 较稳 |
| 3档 | 主体轻微转动、人物头发衣物动 | 人物主视觉、产品展示 | 中等风险 |
| 4档 | 大幅动作、场景转换、复杂操作 | 剧情、演示 | 高风险 |

商业素材建议从 1 档或 2 档开始。

尤其是带 Logo 和产品标签的画面。

不要一上来就要求：

```text
产品 360 度旋转。
人物走过来拿起产品。
屏幕自动打开完整软件界面。
海报里的每个元素都飞起来。
```

这类需求看起来酷。

但失败率很高。

更稳的思路是：

```text
主体不动。
背景动。
光动。
镜头轻轻动。
```

这已经足够让静态图变成视频。

## 7. 产品图生视频模板

适合美妆、食品、硬件、包装、家居。

### 模板一：高级产品广告

```text
保持图片中的产品外形、标签、颜色和摆放位置完全不变，
镜头从正面缓慢推进到产品中近景，
背景出现轻微水雾和柔和高光流动，
光线从左上方轻轻扫过产品边缘，
真实拍摄质感，高级电商广告风格，
5 秒，9:16，
不要改变产品形状，不要改变标签文字，不要新增手部，不要新增人物，不要新增品牌 Logo。
```

### 模板二：科技硬件动效

```text
保持图片中的黑色智能硬件主体和边缘轮廓不变，
产品表面出现非常轻微的高光滑动，
背景里的抽象蓝白光线缓慢移动，
镜头轻微从左向右横移，
干净、克制、企业级科技广告风格，
5 秒，16:9，
不要改变产品结构，不要新增按钮，不要出现文字，不要出现人物。
```

### 模板三：食品饮品氛围

```text
保持图片中的饮品杯、包装和桌面位置不变，
只让杯口附近出现轻微热气，背景光斑缓慢变化，
镜头固定，只有非常细微的推近感，
温暖自然光，真实生活方式广告风格，
5 秒，9:16，
不要改变包装文字，不要新增手部，不要新增人物，不要让液体溢出。
```

产品类图生视频要记住：

```text
产品越重要，动作越要小。
```

## 8. 人物主视觉图生视频模板

人物图比产品图更敏感。

最容易出问题的是：

```text
脸。
眼睛。
牙齿。
手。
头发。
衣服边缘。
```

所以人物图生视频要保守。

### 模板一：头像/主视觉轻动

```text
保持图片中人物的面部特征、发型、服装和姿势不变，
只让头发和衣物边缘有非常轻微的自然风动，
背景光线缓慢变化，镜头保持稳定，
柔和自然光，真实摄影风格，
4 秒，9:16，
不要改变五官，不要改变表情，不要新增手势，不要让人物说话，不要改变服装。
```

### 模板二：课程讲师封面

```text
保持图片中讲师的站姿、面部和服装不变，
背景中的办公室灯光轻微闪动，画面有缓慢推进感，
人物保持自然微笑，不做口播动作，
干净、专业、可信赖的课程封面风格，
5 秒，16:9，
不要改变脸部，不要生成口型，不要改变衣服，不要新增文字，不要新增Logo。
```

人物场景不建议让模型做口播。

口型和声音最好用专门的数字人工具或后期处理。

图生视频更适合做：

```text
主视觉轻动。
背景动效。
封面开场。
```

不要让它承担完整人物表演。

## 9. 海报和封面图生视频模板

海报类图生视频最常见的问题是文字变形。

所以优先建议：

```text
上传无文字版本。
生成动态背景。
剪辑软件里再加文字和 Logo。
```

如果只有带文字海报，就写清楚：

```text
保持文字不变。
不要让文字移动。
不要重绘文字。
```

但即使这样，也要严格验货。

### 模板：知识课程封面动效

```text
保持图片中的整体构图、主色调和人物位置不变，
背景中的抽象线条和光点缓慢流动，
镜头有非常轻微的推进感，
现代、干净、专业的知识课程封面风格，
5 秒，16:9，
不要改变已有文字，不要让文字变形，不要新增文字，不要新增人物，不要改变人物五官。
```

更稳版本：

```text
保持图片中的背景构图和主色调不变，
让背景抽象线条和光点缓慢流动，
镜头轻微推进，
现代、干净、专业的知识课程封面风格，
5 秒，16:9，
不要出现任何文字，不要出现人物，不要出现Logo。
```

然后后期加标题。

第二种通常更稳。

## 10. App界面图生视频怎么做

很多人想把 App 截图变成演示视频。

这件事要小心。

图生视频不擅长精确 UI 操作。

如果你要求：

```text
鼠标点击按钮。
界面跳转到下一页。
表格自动刷新。
文字保持完全准确。
```

模型很容易乱改界面。

更稳的做法是：

```text
把 UI 当作视觉背景，而不是交互演示。
```

Prompt 示例：

```text
保持图片中的 App 界面布局、卡片结构和整体颜色不变，
界面中的抽象数据卡片有轻微发光和柔和浮动效果，
镜头从正面缓慢推进，
现代 SaaS 产品展示风格，干净、专业、克制，
5 秒，16:9，
不要改变界面文字，不要新增按钮，不要让布局变形，不要出现鼠标点击动作。
```

如果你要做真实产品演示，建议：

```text
录屏。
后期加动效。
AI 视频只做开场和氛围素材。
```

不要用图生视频替代精确录屏。

## 11. 首帧、尾帧和分段拼接

如果你的工具支持首帧和尾帧，图生视频会更好控。

最简单的用法：

```text
首帧：视频从哪里开始。
尾帧：视频到哪里结束。
```

比如你做产品广告：

```text
首帧：产品远景。
尾帧：产品近景。
```

模型只需要在中间过渡。

如果只支持上传一张图，也没关系。

用更保守的运镜：

```text
slow push-in
subtle pan
static camera
soft background movement
```

如果要做 30 秒视频，不要强行一条生成。

拆成：

```text
镜头1：产品远景，背景动。
镜头2：产品中景，高光扫过。
镜头3：细节特写，微距推进。
镜头4：使用场景，氛围转场。
镜头5：品牌收尾，后期加 Logo。
```

每个镜头 3-5 秒。

再剪起来。

这和第85期 Sora2 长视频成片的思路一样：

```text
长视频不是拉长。
是短镜头拼稳。
```

## 12. 用 4SAPI 管图生视频工作流

图生视频看起来是视觉工具。

但团队真正麻烦的是管理：

```text
哪张图能用？
Prompt 谁写的？
生成了几版？
哪版通过审核？
商用授权确认了吗？
客户反馈改了什么？
成本花在哪个项目？
```

4SAPI 可以放在图生视频前后。

前面做：

```text
根据图片用途生成 Prompt。
把中文需求翻成英文 Prompt。
检查 Prompt 里有没有夸大宣传。
按平台生成不同画幅的分镜方案。
```

后面做：

```text
归档生成记录。
总结失败原因。
生成客户汇报。
统计每个项目消耗。
输出复盘报告。
```

一个团队最小流程：

```text
设计上传首帧图
  -> 运营填写用途和限制
  -> 4SAPI 生成 3 版 Prompt
  -> 人工选 1 版并修改
  -> 视频工具生成 3-5 版
  -> 审核按清单打分
  -> 剪辑成片
  -> 归档首帧、Prompt、成片、成本和授权
```

如果你的 4SAPI 入口兼容 OpenAI SDK，可以先让模型生成 Prompt。

实际 Base URL、模型名和参数，以 4SAPI 后台当前文档为准。

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["FOURSAPI_API_KEY"],
    base_url="https://api.4sapi.com/v1",
)

request = """
我有一张护肤精华产品图，准备做5秒竖屏图生视频。
要求：产品形状、标签、颜色和位置都不能变。
希望：背景有轻微水雾和高光流动，镜头缓慢推进。
限制：不要新增手部，不要新增人物，不要改文字，不要出现新Logo。

请输出：
1. 中文Prompt
2. 英文Prompt
3. 禁止项
4. 生成后验货清单
5. 如果失败，应该优先改哪三个地方
"""

resp = client.chat.completions.create(
    model="<从4SAPI模型广场复制模型名>",
    messages=[
        {
            "role": "system",
            "content": "你是AI视频广告导演，擅长把首帧图需求改写为稳定的图生视频Prompt。",
        },
        {"role": "user", "content": request},
    ],
)

print(resp.choices[0].message.content)
```

把输出结果存进项目表。

不要只存在聊天记录里。

## 13. 图生视频验货清单

图生视频的验货重点和文生视频不一样。

文生视频看“有没有生成对”。

图生视频看“有没有把原图改坏”。

按这张表查：

| 检查项 | 必看问题 |
| --- | --- |
| 主体 | 产品/人物是否和首帧一致 |
| 边缘 | 产品边缘、脸部轮廓、衣服边缘是否融化 |
| Logo | 是否变形、消失、变成乱码 |
| 文字 | 是否扭曲、漂移、闪烁 |
| 构图 | 主体是否跑偏、被裁掉 |
| 运动 | 运镜是否过猛、是否突然跳帧 |
| 背景 | 是否新增奇怪物体 |
| 光线 | 是否前后不一致 |
| 结尾 | 最后一帧是否还能剪 |
| 商用 | 素材来源和生成平台授权是否确认 |

如果有 Logo 或文字，建议逐帧看。

不要只看缩略图。

很多问题在播放时很明显。

## 14. 成本控制：图生视频更要少试错

图生视频看起来比文生视频可控。

但如果首帧没处理好，它也会烧钱。

建议这样控制：

```text
先用低运动版本测试。
确认主体稳定后，再加一点运镜。
同一个首帧最多测 2-3 种运动方向。
每种方向生成 3 版。
仍然不稳，就回去改图，不要继续刷。
```

失败时优先检查：

```text
首帧是不是太复杂。
文字是不是太多。
Logo 是不是太小。
主体边缘是不是不清楚。
动作是不是太大。
Prompt 是否要求模型改变主体。
```

不要把所有失败都怪模型。

很多时候，改首帧比改 Prompt 更有效。

## 16. 常见坑

### 坑一：首帧里文字太多

解决：

```text
做无文字版本。
视频生成后再加字。
```

### 坑二：让产品做大动作

解决：

```text
产品保持不动。
让高光、背景、镜头动。
```

### 坑三：人物图要求口播

解决：

```text
图生视频只做主视觉轻动。
口播交给数字人工具或后期。
```

### 坑四：Logo 太小

解决：

```text
Logo 后期叠加。
或者让视频生成版本不带 Logo。
```

### 坑五：横图硬转竖屏

解决：

```text
先重新设计 9:16 首帧。
不要指望模型自动补干净两侧画面。
```

### 坑六：只保存成片，不保存首帧和 Prompt

解决：

```text
每个可用版本都存首帧、Prompt、参数、工具、生成时间和授权状态。
```

## 17. 一个完整案例：产品图做5秒竖屏广告

假设你有一张护肤精华产品图。

目标：

```text
做一条小红书 5 秒竖屏动态素材。
```

首帧要求：

```text
9:16。
产品居中。
瓶身完整。
背景干净。
少文字。
Logo 不要太小。
```

Prompt：

```text
保持图片中的护肤精华瓶外形、瓶身标签、颜色和居中位置完全不变，
背景中出现非常轻微的水雾流动和柔和高光变化，
镜头从正面缓慢推进，运动幅度很小，
自然晨光，干净高级的美妆广告风格，
5 秒，9:16，
不要改变瓶身文字，不要改变 Logo，不要改变产品形状，不要新增手部，不要新增人物，不要新增其他产品。
```

生成策略：

```text
先生成 3 版。
如果产品稳定，选最好的一版进剪辑。
如果 Logo 变形，改成无 Logo 版本首帧，后期叠 Logo。
如果产品边缘融化，降低运动幅度。
如果背景太乱，换更干净首帧。
```

剪辑时加：

```text
标题。
卖点。
价格或活动信息。
品牌 Logo。
轻音乐。
结尾 CTA。
```

不要让视频模型生成这些文字。

它负责让画面动起来。

营销信息交给后期。

## 18. 发布前检查清单

```text
[ ] 首帧来源和授权已确认
[ ] 首帧画幅已按发布平台准备
[ ] 首帧主体清楚，背景干净
[ ] Prompt 明确写了保持主体不变
[ ] Prompt 明确写了禁止改变 Logo、文字、人物脸或产品形状
[ ] 使用的是 1-2 档运动，不是上来就复杂动作
[ ] 已生成 3 版以上并记录失败原因
[ ] 已逐帧检查 Logo、文字、产品边缘和人物脸
[ ] 字幕、标题、价格、CTA 已在剪辑软件中添加
[ ] 素材、Prompt、成片和授权已归档
[ ] 团队项目已在 4SAPI 或内部系统记录 Prompt、审查和成本
```

## 19. 总结

图生视频比文生视频更适合商业素材。

原因很简单：

```text
它有首帧。
它有主体锚点。
它更容易保持品牌和构图。
```

但图生视频也有边界。

它最擅长：

```text
让静态图轻微动起来。
让产品图变成短视频。
让封面图变成开场。
让海报背景有动态。
让人物主视觉更有呼吸感。
```

它不擅长：

```text
复杂剧情。
精确口播。
大幅动作。
精准 UI 操作。
完整工业流程演示。
```

真正稳的做法是：

```text
先做好首帧。
再控制运动。
再严格验货。
最后后期加文字和 Logo。
```

个人使用时，它是静态素材动起来的快捷工具。

团队使用时，它应该进入完整生产流程：

```text
4SAPI 管 Prompt、审查、归档和成本。
视频工具管生成。
剪辑工具管信息表达。
```

文生视频负责从无到有。

图生视频负责从静到动。

这两条线分清楚，AI 视频才会真正变成生产力，而不是积分抽奖。
