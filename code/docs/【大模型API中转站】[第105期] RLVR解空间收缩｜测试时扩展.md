# 【大模型API中转站】[第105期] RLVR解空间收缩｜测试时扩展

强化学习把模型的单次答题准确率拉高了，却悄悄收窄了它的解题思路范围。思路越窄，靠"多想几步"拿更高分的空间就越小。

这个此消彼长的关系，直接影响接入时的推理成本配置。这篇拆解 RLVR 训练带来的解空间收缩现象，以及按任务动态分配推理预算的接入做法。

## 一、开篇痛点

推理模型的标准用法是"多想想再回答"：一次调用让模型生成多个候选答案，再挑最优。这个技巧叫测试时扩展（test-time scaling），代价是 token 成本成倍上升。

但问题来了：如果模型的解题思路本身很窄，生成 10 个候选答案可能都是同一条思路的变体，扩展的收益就很差。钱花了，准确率没怎么涨。

研究数据证实了这一点：可验证奖励强化学习（RLVR）大幅提升单次准确率（pass@1），但导致策略的解空间收缩，测试时扩展的收益随之缩水。

## 二、RLVR 做了什么

RLVR 的思路很直接：给模型一个可自动验证的奖励信号，比如"答案是否与标准结果一致"，用强化学习让模型更频繁地给出正确答案。

```text
RLVR 之前：模型自由探索多种解题路径，正确率一般
    |
    v
RLVR 之后：模型收敛到少数高奖励路径，pass@1 上升
    |
    v
代价：路径多样性下降，备选思路变少
```

| 指标 | RLVR 前 | RLVR 后 |
| --- | --- | --- |
| pass@1（单次准确率） | 中等 | 大幅提升 |
| 解空间多样性 | 高 | 明显收缩 |
| 测试时扩展收益 | 高 | 明显下降 |

## 三、为什么解空间收缩是坏事

测试时扩展依赖多样性：

```text
多样化解空间：候选 A、B、C 思路不同，答案分布广
    |
    +----> 采样 10 次，至少一次接近正确
    |
收缩解空间：候选 1、2、3 都是同一条思路
    |
    +----> 采样 10 次，全在同一个错误区域
```

如果模型只会一条思路，那"多采样"就是重复劳动。单次准确率再高，也只覆盖那条思路能解决的问题；遇到思路外的题目，采样再多也没用。

## 四、对接入成本的影响

这直接影响推理预算怎么花：

| 场景 | pass@1 高 | pass@1 低 |
| --- | --- | --- |
| 解空间宽 | 采样 2-3 次即可 | 采样多次，收益递减 |
| 解空间窄 | 采样 1 次就够 | 采样再多也难提升 |

接入时的正确做法不是固定采样次数，而是先测目标模型的解空间特征，再决定扩展策略。对收敛型的模型，把预算花在采样上不如花在提示词优化或换模型上。

## 五、按任务动态分配推理预算

- 不同任务用不同采样次数，不为所有任务支付同样的扩展成本；
- 采样时温度调高（0.8 左右），保证候选有差异，避免采样出同一思路的重复结果。

## 六、用一致性检验解空间宽度

不用等论文数据，我自己就能粗测一个模型的解空间宽度：

1. 选 10 道同一类型的题；
2. 每道题采样 5 次；
3. 统计 5 次答案之间的差异度（关键词重叠率、结构相似度）；
4. 差异度高的模型解空间宽，差异度低的说明思路收敛。

```text
答案 1：用二分法求解
答案 2：用二分法求解，步骤略不同
答案 3：用二分法求解，几乎相同
=> 解空间窄，采样 5 次只有 1 条思路
```

这个测试成本极低，几分钟就能完成，但对推理预算配置很有指导意义。

## 七、成本与风险提示

- pass@1 提升不代表总准确率提升：解空间窄时，采样收益有限；
- 采样次数不是越多越好：收益曲线会饱和，超出饱和点就是浪费；
- 温度过低会导致候选重复：采样时保持 0.7-0.9 的温度；
- 任务分级要基于实测：不同任务类型的最优采样次数不同；
- 合规接入：只通过合法渠道调用模型，不涉及任何违规方案。

## 八、接入检查清单

1. 用一致性检验粗测候选模型的解空间宽度；
2. 按任务类型配置模型档位与采样次数；
3. 采样时设置合适温度，确保候选多样性；
4. 记录不同采样次数下的准确率曲线，找到饱和点；
5. 解空间窄的模型不盲目增加采样，考虑提示词优化或换模型；
6. 把采样策略接入成本报表，对比单任务成本变化。

## 九、我的结论

RLVR 带来的解空间收缩不是缺陷，而是成本特征：这类模型单次调用更便宜、更精准，但别指望靠"多采样"弥补思路盲区。接入策略要反过来——识别任务类型，该单次就单次，该多次才多次，把推理预算花在刀刃上。
